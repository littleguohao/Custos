## 总原则

当不同 Agent 结论冲突时，按以下优先级处理：

1. 风控纪律
2. 市场环境
3. 板块状态
4. 个股质量
5. 买点计划
6. 仓位效率
7. 短线机会

## 核心规则

### 0. 同一事实的多个读数：按**证据新鲜度**取（2026-08-07 定案）

风控优先（下面第 1 条）说的是**同等新鲜度**下风控压过买入意愿。
当两个组件对同一只票给出冲突结论、而它们的**依据日期不同**时，取更新的那个。

具体到 14:45 盘中：

| 组件 | 依据 | 结论 |
|---|---|---|
| `review_core` 重算的 B1 | **14:45 实时行情** | ✅ 以此为准 |
| 当日 `risk_decision` | **前一交易日收盘** | 作为参照，理由必须仍可见 |

⚠️ 为什么当日 risk_decision 的依据是 T-1：`generate_risk_and_sectors` 在
`daily_pipeline` 里**不受 session_type 限制**，所以 **09:05 盘前就会产出**当日
risk_decision —— 那时当日 K 线还不存在。它打着当日日期，依据却是前一交易日收盘。

代码级体现：
- `review_core.classify` 里 B1 的 P0/P1/P2 短路 return 排在 `high_risk` 之前
- 但**高优先风控的理由必须仍然可见** —— 短路时会附「⚠️未消化的高优先风控依据：…」
  （`risks` 只经由 `classify` 影响 14:45 报告，不补就一个字都看不到，而「所有计划必须可复盘」）
- `risk_decision.evidence_date` 记录依据日；14:45 报告据此标注，不再按文件名判「当日」

**17:00 盘后不适用**：那时两边依据都是当日收盘，回到下面第 1 条（风控优先）。
`chief_decision` 里高优先风控会覆盖 B1 动作，但**不得把 B1 已判的 P0 降成 P1**（v0.34）。

---

### 1. 风控优先

只要 risk_control 触发以下任一情况，买入或加仓计划自动降级或取消：

- 个股在冷却名单
- 单票亏损超过阈值
- 技术破位未修复
- 板块退潮
- 无明确止损位
- 当月短线熔断

### 2. 市场许可优先

market_timing 为防守/冰点时：

- 原则不新开仓
- 不追高
- 不做突破买入
- 不因 J 值低位买入
- 只允许观察或极小仓位试探待总控确认

补充：

- 左侧趋势中，价格深跌、周线/月线 KDJ 的 J 值为负和低估值，只能提高观察优先级，不能越过市场许可和止跌确认直接买入。
- 右侧趋势中，日线 KDJ 的 J 值出现大负值，只能作为趋势内超跌候选，必须等待修复信号。
- 单独出现的 `J` 均指 KDJ 的 J 值。

0AMV 空头区间：

- 买入计划默认降级
- A池门槛提高
- 加仓需要强验证

0AMV 被 market_timing 确认为“活跃实质空头区间”时：

- 所有反弹首先按减仓机会处理，不按趋势反转或新增买点处理
- 禁止借反弹加仓、摊低成本或扩大总仓位
- 后排股、弱于板块个股、破位股和高仓位持仓优先利用反弹降仓
- 只有 0AMV 明确退出实质空头区间，且大盘、板块和个股结构完成修复确认后，才允许撤销本约束
- 0AMV 数据缺失、过期或判定未确认时，不得擅自声称已退出空头区间

### 3. 板块优先于个股

板块退潮：

- 后排股禁止买入
- 持仓进入风控观察
- 个股技术低位不构成买点

板块主升/修复：

- 只优先核心股、中军、强趋势股
- 后排补涨不作为主要策略

### 4. 选股优先于买点

没有进入 stock_pool A池的股票，不允许 buy_strategy 输出正常买入。

B池只能输出观察价位。

C池不生成交易计划。

D池禁止生成买入计划。

### 5. 止损先于买入

任何买入计划必须先定义：

- 技术止损位
- 亏损止损阈值
- 时间止损条件
- 逻辑无效条件

缺任何一项，不允许输出“允许买入”。

### 6. 加仓比买入更严格

加仓必须满足：

- market_timing 不低于震荡偏强
- 0AMV 不为空头
- 板块强于大盘
- 个股强于板块
- 首仓已有浮盈或逻辑被验证
- risk_control 未触发风控

禁止亏损摊低式加仓。

### 7. 持仓处理优先于新开仓

当存在破位/浮亏扩大持仓时：

- 先处理风险持仓
- 再考虑新开仓
- 总仓位不应因新买入而突破 market_timing 上限

## 典型冲突处理

| 场景 | 处理 |
|---|---|
| market_timing 防守，但个股 J < 12 | 观察，不买入 |
| 板块退潮，但个股接近箱体下沿 | 观察或回避，不低吸 |
| stock_pool A池，但无止损位 | 不允许买入 |
| buy_strategy 允许买入，但 risk_control 否决 | 取消买入 |
| 持仓浮亏 -8%，但产业逻辑好 | 先进入风控评估，不盲目补仓 |
| 0AMV 处于活跃实质空头区间，持仓出现反弹 | 优先制定减仓计划，不加仓、不按反转追入 |
| 个股突破，但板块分歧 | 不追高，等待确认 |
| 近期短线连续亏损，但出现短线热点 | 降低仓位或放弃 |

## 总控输出约束

chief_decision 最终输出必须包含：

- 允许动作
- 禁止动作
- 持仓处理优先级
- 买入计划是否执行
- 风控依据
- 明日验证点

如果存在冲突但无法判断，默认选择更保守方案。
