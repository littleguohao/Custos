# B1 回测调查结论与框架（2026-07）

> 目的：沉淀 B1（J<13 反转买点）系统性回测的**结论、框架形态、偏差警示、工具用法**，
> 防止后续重复踩坑或误把有偏结果当实盘预期。**所有内容为研究结论，未改动任何线上买入逻辑。**

## 0. 一句话结论
**B1 的可辩护框架 = 0AMV择时 + 反转K入场(J<13+缩量企稳) + 带空间的止损 + BBI移动止盈 + 分散多槽。**
per-trade 有正 edge（跨止损参数稳健），但**收益数字被幸存者/牛市窗/肥尾严重高估**，
真实预期应为**个位数 CAGR、中等回撤的稳健策略，而非暴利机器**。
日线价量**形态/选股**（S_shape/买弱/reversal_quality/reversal_quality_inv）**均无 alpha——随机择优 ≥ 花哨选择器**
（含反向"选丑"：经含退市股跨年 walk-forward 证伪，其样本内 edge 本质是幸存者偏差）；
edge 来自**择时 + 分散 + 交易管理**，不是选股。

## 1. 工具：`07_tools/screening/backtest_factors.py`
研究用回测器（只读本地日线，不改线上）。可组合的开关：
- **入场门槛 `--entry-filter`**：`none` / `j_low`(J<13) / `reversal_k`(J<13+缩量+量底+小实体+小振幅) / `j_macd_turn`(J<13+MACD柱上行)。
- **打分/选择器 `--scorer`**：`baseline`(不选) / `reversal_quality`(反转成色0-4) / `s_shape` / `b1_pullback` / `alpha101` / `alpha_pvcorr` / `low_vol` / `momentum`。
- **交易模拟 `--trade-sim`**：进场=可买日收盘；`--stop-mode low|pct`(+`--stop-pct`)；BBI 移动止盈(站上BBI后连破`--bbi-consec`日卖)；`--time-stop`。
- **择时 `--amv-long-only`**：仅 0AMV『做多』区间进场(读指南针 compass_amv 历史)。
- **组合 `--portfolio`**：固定风险仓位 `--risk-pct`，`--max-concurrent`/`--max-pos`；`--top-n` 横截面择优；`--cost-bps` 成本。
- **周线 `--weekly`**；**内存**：流式逐股加载 + `--max-signals-per-code` + `--summary-only`。
- **数据源 `--data-source tdx|qlib|csv`**(默认 tdx):qlib/csv=`E:\S_DATA`(**含退市股、前复权**,1999-11→2026-02);
  配 `--start/--end` 指定回测区间(walk-forward 用)、`--universe-sdata` 用其全市场宇宙(含退市,可去幸存者偏差)。

## 2. 关键结论（按逻辑链）
1. **日线价量形态无短周期 alpha**：S_shape、"买弱"评分在全市场阈值扫描下无 lift（方向A）。
2. **"完美B1"指纹(10只赢家反标)作进场过滤有害**：`compute_b1_pullback_fit` recall 100%，但全市场周线交易模拟
   期望 -0.42%/笔，劣于无差别进场 baseline(+0.96%)——买弱指纹排除了做多区间的突破赢家。**仅描述性，不作买入依据。**
3. **固定 horizon 回测为负；edge 出现在交易管理**(止损截断 + BBI 移动止盈让利润奔跑)。
4. **0AMV做多择时有价值**：baseline+AMV 期望 +0.96%/笔（引入 J<13 前）。个股服从大盘，坐实。
5. **J<13 单用**：**周线为负**(接飞刀，均亏深)、**日线为正**(+2.06%)。"买入K最低"止损对超卖贴低K**过紧→秒止损**(83.7%被扫)。
6. **反转K(J<13+缩量企稳)是关键过滤**：排除飞刀。配**带空间止损**(pct 6~12% 全为正期望，8% 甜蜜点)，
   per-trade edge **跨止损参数稳健**(非过拟合单点)。但信号稀少→5槽组合 CAGR 仅约 3%(容量受限)。
7. **杠杆在容量/分散，不在门槛**：5槽组合下 j_low/reversal_k/j_macd_turn 的 CAGR 近似(2-3%)，
   因组合被并发上限卡住；`total_R` 具误导性(全候选池≠组合选中子集)。**更多小槽分散**降回撤。
8. **横截面择优：正向无用，反向(contrarian)经真样本外验证后证伪**：
   - 正向按"教科书反转成色"(reversal_quality)择优 **劣于随机**(baseline top-5 +43% > reversal_quality +33%)。
   - 特征归因(train/test)：8 因子中仅 reversal_quality 一致，且为**稳健负预测**(train −3.42%/test −2.75% Q4−Q1)——越教科书越差。
   - 反向择优 `reversal_quality_inv` 曾在同偏样本内大胜(+69.4% vs +43%)，但 **2026-07-28 含退市股跨年 walk-forward
     (7窗口×同宇宙300只,qlib前复权,成本25bps)证伪**：仅在 2019-20 一个窗口胜出(+16.2% vs +0.8%);
     2007-08/2011-12/2013-15/2021-26 四窗负于随机，其中**同一 2021-08~2026-02 窗口从幸存者宇宙的 +69.4% 翻转为
     含退市宇宙的 −11.9%(baseline +16.4%)**——"选丑"选到的相当部分是走向退市的烂票,
     **当初的 contrarian edge 本质就是幸存者偏差**。结论:reversal_quality_inv 不可用作选股依据;选股层面维持
     "随机/等权 ≥ 一切价量选择器"。JSON 证据:`06_logs/walkforward/`。
10. **板块相位择时(--sector-filter)：OOS 两窗验证加值(尤其熊市)**——用板块指数(880xxx)MACD相位
    (DIF>0且无近期顶背离/三打=有利)门槛个股进场。含退市 walk-forward 两窗(A无/B有,同0AMV):
    - 熊市窗(2021-08~2023-12)：B **-24.9% vs A -31.4%**(少亏6.5pp,避开塌方板块),回撤相近。
    - 牛市窗(2024-01~2026-02)：B 回撤 8.6% vs 10.7%、收益/回撤 4.4 vs 3.65(略让收益换更稳;牛市多数板块有利,过滤少咬)。
    - **结论:板块相位择时是继 0AMV 之后第二个 OOS 站得住的增强,主要价值在熊市/轮动减亏。** 成员用当期TQ映射(轻微漂移)。
    ⚠️ 即便如此,全栈(0AMV做多+板块+B1+止损/BBI)在 2022 熊市仍亏~25%——**长多B1非bear-proof,择时减亏非免疫**;
    0AMV做多会被熊市反弹whipsaw(粘滞动量regime)。熊市要不亏只能靠空头期空仓(已在做)或策略外做空。
    - **2×2 分层归因(熊市窗 2021-08~2023-12,含退市)**:无AMV无板块 -46.2% / 无AMV有板块 -42.0% /
      有AMV无板块 -31.4% / 有AMV有板块 **-24.9%**(四者最优)。→ **0AMV 贡献 ~15pp(主过滤器)**,
      **板块相位 ~4-6pp(辅助,主要提胜率+4.9pp 非盈亏比)**,**两者叠加最佳**。价值排序:0AMV ≫ 板块 > 选股(0/负)。
      但**即便叠加,2022 仍亏 ~25%** → 长多非 bear-proof;真正的熊市保护是**空头期空仓**(0AMV空头不买,live 已做)。

11. **0AMV 入场择时"迟到"(起涨点研究,2024-09~2025-06;2026-07-28 修复 buffer 后复核)**：多头区间涨最好的赢家,其系统可选起涨点
    (reversal_k,排除0AMV)**73% 落在空头**(300/411),空头转做多**中位领先12交易日**(p25 6/p75 24/max 76,n=300)。
    ⚠️ 此前"98%空头/中位23天"系 **`--buffer-days` 未生效**(数据加载起点=start,起涨点无法早于 start)的截断假象;
    修复后方向不变(多数起涨点仍在空头、0AMV 迟到),但**幅度缩水一半**(98%→73%,23天→12天)。
    ⚠️ **事后/幸存者视角**:赢家与起涨点都后视选出(挑了底部),且**只数赢家起涨、未计空头里的飞刀**。
    **不能推出"放宽0AMV"**——已证空头广撒 B1 = -EV(熊市-46%,加板块过滤仍-42%),赢家与飞刀都在空头见底、实时分不出。
    0AMV 迟到 = 避开空头屠杀的**代价/权衡**,非错误。要吃这~12天须**实时判别子**:价量(无alpha)、板块相位(单独不够,-42%)均不行;
    唯一未测=**基本面优**(真公司早见底 vs 垃圾飞刀),但无法回测(look-ahead)→ **live 验证**。
    **前哨机制已就位**:candidate_table 观察区里标 `待0AMV做多` 者=基本面优+板块有利+技术强但0AMV未多头,正是候选早期起涨
    ——**live 前瞻观察其是否领先0AMV跑赢**,验证"空头尾部有限度提前埋伏(带基本面+共振硬门槛+小仓)"是否成立。
    - **多窗复核(4窗)→ 领先量极不稳定**:反弹22春 **0%空头(0AMV当时及时/领先,起涨点全落做多)**、22冬 96%空头/领先中位5天、
      24春 61%/中位53天、2024-09 修复后 73%/中位12天(修复前误为 98%/23天)。**没有可机械化的固定提前量**(0→53天)。
      (注:前三窗为 buffer 修复前口径,领先幅度可能同样系统性偏高,结论方向不受影响。)
      → **"提前N天进场"规则不成立**(事前不知领先/滞后与幅度)。**前哨须"条件驱动"(共振成立即观察/小仓),非"时间驱动"**;
      是否能靠条件(基本面+共振)分出赢家vs飞刀,仍只能 live 观察验证。
    - **赢家板块族聚集分析(2026-07-29,板块族多重归属+密度归一,`launch_*.json`)**:密度榜与各窗真实主线完全吻合——
      22春=新能源链(固态电池29%/锂电24%/光伏23%)、22冬=疫后修复+AI萌芽(新零售17%/AI智能体14%/DeepSeek13%)、
      24春=低空经济/无人机(18%/17%)、24-25=机器人/阿里概念(18%)——**板块族+密度是准确的"窗口主线指纹"**(归因工具)。
      但:①各窗前5集中度仅 9~14%,反弹赢家天然散布 350+ 板块,普涨本质;②主流内赢家收益 vs 分散 = **+10.3 / -0.6 /
      +6.4 / -16.7pp**(结构反弹主流强、全面牛市分散妖股更强)→ **"跟随主流"机械规则不成立**(与 trade-sim 口径 +0.19pp 互证);
      ③赢家数 vs 板块指数收益相关≈0(仅24春弱正0.12)。**落地形态=live 跟踪当期密度榜变化辅助前哨解读,不做进场 gate。**

9. **外部因子借鉴**：
   - 101 Formulaic Alphas(Kakushadze)：核心可借=**横截面ranking选股**(非绝对阈值)；alpha 多为超短反转/市场中性，与 B1 不同源，仅作选择器候选(alpha101/alpha_pvcorr)。
   - Fama-French 3/5：**风险/归因模型非信号**；A股应用 CH-3/CH-4(壳调整size+EP+换手)；可借=归因严谨性(alpha vs beta) + 特征溢价选择器(low_vol/momentum)。

## 3. ⚠️ 偏差警示（务必牢记，否则会把有偏结果当真）
- **幸存者偏差**：`--universe-local` 只含**今天仍存续**的票，退市/暴雷全剔除 → 做多+移动止盈系统性高估。**无退市数据无法消除**，结果只能视为**乐观上界**。
- **regime 偏差**：`--amv-long-only` 只在牛市段进场；牛市做多本就赚 → 部分是 **beta 非 alpha**。
- **肥尾/均值陷阱**：池均期望曾达 +15.16%/笔（不可信），系少数幸存者 moonshot 拉高 **mean**；**看 `median_return` 与被选中子集**，不看池均值。
- **窗口敏感**：`--count` 250→500 使池期望 -0.15%→+15.16%（25倍）——**稳健策略不会因历史长度翻天**。当前回测仅取"最后 count 根"，**无 walk-forward/样本外**，跨年份稳健性未验证。
- **周线止损失真**：周线止损按周级执行，跳空低开尾损被夸大。
- **回撤口径乐观**：组合资金曲线的最大回撤按**平仓时点已实现权益**计，**不含持仓中浮亏**——
  文中所有回撤/收益回撤数字(13.6%、3.16、4.91 等)均为**乐观下界**，真实峰谷回撤更大。
- **s_data(qlib)数据特性**：①**前复权**(与 tdx 比价,因子随分红阶梯;收益率口径正确,绝对价位≠盘面);
  ②两个 bundle 间有**缺口 2020-09-28→2021-07-30**(约10个月,跨年回测该窗无数据);
  ③止于 2026-02-06,之后仍靠 tdx;④含退市股=可消幸存者偏差,但退市股末日数据截至退市前(如300104→2020-07-20)。

## 4. 当前"最佳配置"（有偏上界，非实盘预期）
`--entry-filter j_low --amv-long-only --stop-mode pct --stop-pct 8 --bbi-consec 2`
`--portfolio --risk-pct 1 --max-concurrent 15 --max-pos 6 --top-n 5`（**择优器用 baseline 即可，reversal_quality 反而更差**）
- 同口径对照：`baseline`(随机top-5) CAGR ~20% / 回撤 ~14% / 收益回撤 ~3.16，**优于** `reversal_quality`(~16%/16%/2.12)。
- 绝对数被**幸存者+牛市窗+肥尾**高估，**不可作实盘预期**；相对对照(随机≥选择器)有效。
- 作为**证据层候选打分/排序**接入是合理的；**不需要形态选择器**——简单随机/等权即可。
