## 主题

live 技术分（`technical_score`，1800 候选表的分层/排序依据）能否预测信号后的涨幅

## 目标

回答 owner 三问：0AMV 做多区间收益最好的 50% 股票，信号出现时的技术分分布如何；
得分与涨幅是否正相关；带上真止损策略后结论是否变化。

## 结论

**① 技术分与涨幅不正相关（弱负），且跨窗稳定。** 无止损基线（14469 笔）：
Spearman −0.062 / Pearson −0.027；前后半窗同负（−0.075 / −0.046）；86 个有效
0AMV 做多区间 62 负 24 正。**收益 top-50% 组的技术分均值（40.5）反而低于
bottom-50%（43.7）**——涨得最好的半数并没有更高的分。

**② 加真止损后相关性进一步稀释到 ≈0，且前后半窗翻转。** 5% 止损臂 Spearman
−0.011（前半 −0.046 / 后半 **+0.027**，不一致）；5%+成本区臂 −0.030（同翻转）。
「技术分预测不了涨幅」与出场机制无关——三维度第一次实跑即验证：因子轴的
预测力缺陷不是出场能补的。

**③ 结构不是噪声，是胜率/盈亏比互换，且被止损放大。**

| 技术分档 | 胜率（无止损→5%→+cz3） | 盈亏比（无止损→5%→+cz3） |
|---|---|---|
| <30（弱） | 50.6% → 42.3% → 37.0% | 1.51 → 1.76 → 2.21 |
| 30-59（中） | 47.8% → 42.7% → 38.6% | 1.61 → 1.88 → 2.24 |
| ≥60（强） | **38.5% → 33.4% → 31.3%** | **1.85 → 2.19 → 2.37** |

强档 = 更少命中、单笔飞得更远。若走盈亏比路线（owner 核心思想），强档的
「低胜率高盈亏比」属性与止盈止损驱动的打法自洽——但**这说的是分档的行动
语义（怎么拿、怎么止盈），不是排序语义（谁更会涨）**。

**④ 止损在该口径下是净成本。** 全体均收 +1.44%（无止损）→ +0.92%（5%）→
+0.77%（5%+cz3），单调下降——5% 止损截大亏的同时截掉了 34% 笔数的
「跌破后修复」（止损出场均收 −6.9%）。与 R10「纯出场改善跨窗翻负」同向印证：
**出场机制不能单独评价**（三维度搭配原则的又一次实证）。

口径：固定研究基底（0AMV 做多 + J<13，v0.93）× BBI 止盈（站上后连破 2 根
收盘清仓）× 25bps × live `technical_score` as-of 复刻（v0.87 检测器族，
