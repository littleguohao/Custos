## 主题

#61 的改问（owner 2026-10-09 拍板）：校准的目标函数**已由 objective
v2.1 承担**（margin 单量 + 相对 rdd 门——不预测涨幅、看盈亏比/胜率
组合、不受行情牵连，满足 #61 当初全部要求），**不需要重新定义**。真正
空着的是「**分层行动语义**」：分数决定行动档、行动档决定仓位——所以
应该**按层评**而不是按排序评。这是核心原则「杠杆加在仓位」在打分轴
上的落点，战役壳预留的仓位轴正好接在这里。

## 目标

判两个有先后的问题：①**单调性（硬前提）**——出场固定时，V0 分数三档
的 margin 是否双窗满足 高 ≥ 中 ≥ 低；②**仓位增量（问法本体）**——
同一批信号按档分配仓位，对比等仓位是否有增量。**单调性不成立就不再
测仓位增量**（先验偏低：R36 排序器与过滤器两路线已证伪，分层=粗排序
×仓位）；不成立时的结论「capital_intent 那批因子维持 candidate」是
合法结局。非目标（写死）：不调权重（四轮调权证伪的教训）、不挖新轴、
LLM 不碰数值、不改引擎（组合层未测的边界写死见 C3）。

## 结论

**待跑数**（预注册落档 2026-10-09）。结局四态读法（写死）：**candidate**
（C1~C4 全过 ⇒ C5 pre2019 单独终步——**C2 和 C3 都过线才启动**，owner
拍板发令）；**falsified**（C2 单调性不过 ⇒ 当场收口，C3 起不再启动；
或 C4 confirmed_fail）；**untested**（C1 样本不足=不可判，不判
falsified——样本不足≠否定证据，v0.301 哲学同族）；**provisional**
（C4 池未满）。⚠️ candidate 成立的含义**只到「分层有单调性且仓位
倾斜有增量」为止**——接不接进 live 仓位规则是另一轮 owner 拍板
（candidate→active 流程），本单元不直接产出 live 变更。

### 判据（跑数前写死）

- **R42-C1（样本量）**：每档每窗 n ≥ 50（collect_all 口径下判定窗每档
  ~130+ 笔，门槛有余量）；**不过 ⇒ untested 不判 falsified**；
- **R42-C2（单调性，硬前提）**：双窗都满足 margin(高) ≥ margin(中) ≥
  margin(低) **且** 高−低 > 0。**打平读法写死**：按字面「≥」——
  「高=中>低」算过（只要高−低>0），「高>中=低」也算过；任何一处
  倒挂（<）即不过。C2 不过 ⇒ **falsified 当场收口**，C3 起不再启动；
- **R42-C3（仓位增量，问法本体）**：指标 = **加权 expectancy_R
  （Σw·R/Σw）对比等权**（owner 2026-10-09 更正：margin 是逐笔不加权
  量——胜率−盈亏平衡胜率——按档调仓位改变不了它，原方案「对比等
  仓位 Δmargin」会恒等于 0，作废）。**权重格 3 组事先写死不搜索**，
  每组归一化到**平均权重=1**（总敞口与等权基准一致——Δ 不被敞口
  驱动，这正是 rdd 门要防的情形，归一化从结构上控制）：

  | 组 | 原始权重 {高,中,低} | 归一化后 | 机制 |
  |---|---|---|---|
  | W1 | 1.5 / 1.0 / 0.5 | 1.50 / 1.00 / 0.50 | 线性倾斜 |
  | W2 | 2.0 / 1.0 / 0.0 | 2.00 / 1.00 / 0.00 | 强倾斜（低档不做） |
  | W3 | 1.5 / 1.0 / 1.0 | 1.29 / 0.86 / 0.86 | 只加码高档 |

  ⚠️ **W2 低档权重 0 = R36 Phase 4 已证伪的过滤器路线**——保留它
  是做对照，读数时必须注明（过滤器证伪 v0.292 在案）。判定：任一组
  双窗加权 expR > 等权 ⇒ 过。

### 写死的风险注记（判读时逐条核对）

1. **先验偏低（写死）**：R36 排序器路线与过滤器路线均已证伪，分层
   本质是粗排序再乘仓位——C2 判负是大概率、是合法结局（维持
   candidate 现状），判正需 C4/C5 双保险；
2. **分档切点的选择效应**：切点估自挖掘窗是双窗纪律允许的唯一
   数据驱动；换窗切点漂移的敏感性由 C2 双窗同要承担；
3. **组合层未测的边界**：C3 的增量是交易层口径，仓位倾斜在组合层
   （资金曲线/回撤）的净效应本单元给不出——判读时不得把交易层
   增量直接外推成组合层结论；
4. **W2 对照读法**：W2 若「过线」而 W1/W3 不过，读作「过滤器效应
   残存」而非「分层成立」——报告里 W2 单列对照段，不与分层结论
   混读。
