## 主题

#61 的改问（owner 2026-10-09 拍板）：校准的目标函数**已由 objective
v2.1 承担**（margin 单量 + 相对 rdd 门——不预测涨幅、看盈亏比/胜率
组合、不受行情牵连，满足 #61 当初全部要求），**不需要重新定义**。真正
空着的是「**分层行动语义**」：分数决定行动档、行动档决定仓位——所以
应该**按层评**而不是按排序评。这是核心原则「杠杆加在仓位」在打分轴
上的落点，战役壳预留的仓位轴正好接在这里。

## 目标

判两个有先后的问题：①**单调性（硬前提）**——出场固定时，V0 分数三档
的 margin 是否双窗满足 高 ≥ 中 ≥ 低；②**仓位增量（问法本体）**——
同一批信号按档分配仓位，对比等仓位是否有增量。**单调性不成立就不再
测仓位增量**（先验偏低：R36 排序器与过滤器两路线已证伪，分层=粗排序
×仓位）；不成立时的结论「capital_intent 那批因子维持 candidate」是
合法结局。非目标（写死）：不调权重（四轮调权证伪的教训）、不挖新轴、
LLM 不碰数值、不改引擎（组合层未测的边界写死见 C3）。

## 结论

**待跑数**（预注册落档 2026-10-09）。结局四态读法（写死）：**candidate**
（C1~C4 全过 ⇒ C5 pre2019 单独终步——**C2 和 C3 都过线才启动**，owner
拍板发令）；**falsified**（C2 单调性不过 ⇒ 当场收口，C3 起不再启动；
或 C4 confirmed_fail）；**untested**（C1 样本不足=不可判，不判
falsified——样本不足≠否定证据，v0.301 哲学同族）；**provisional**
（C4 池未满）。⚠️ candidate 成立的含义**只到「分层有单调性且仓位
倾斜有增量」为止**——接不接进 live 仓位规则是另一轮 owner 拍板
（candidate→active 流程），本单元不直接产出 live 变更。

### 功效（跑数前 MDE 估算，v0.326，owner 方法论 review #2 首个用例）

输入取最接近的同口径历史读数（R37 战役：V0+j_low+0AMV、collect_all、
R10 策展出场族）：n/档 ≈ 133（挖掘窗 ~400/3）、wr ≈ 0.46。
`power_mde` 公式（SE 下界——payoff 噪声忽略，真实 MDE 只会更大）：

| 比较 | n | ρ 场景 | MDE(2SE) |
|---|---|---|---|
| 相邻档 margin 差（3 档） | 133/档 | 0.3 / 0.5 / 0.75 | **0.102 / 0.086 / 0.061** |
| 高/低档 margin 差（若并 2 档） | 200/档 | 同上 | 0.083 / 0.071 / 0.050 |
| C3 加权 expR vs 等权（全量配对） | 400 | 0.75 | **0.035** |

参照系：R36 时代因子 margin 量级 ~0.03~0.09。**相邻档差在 3 档口径
下基本检测不到**（除非 ρ 很高且效应很大）；并 2 档只改善 ~20% 且
行动语义退粗（owner 不采）；**C3 的加权 expR 配对比较是本设计最
灵敏的判据**（MDE≈0.035，与合理效应同量级、贴线可用）。
⇒ **owner 拍板采 A（2026-10-10）**：保 3 档 + MDE 判读条款（写进
C2/C3 条），C3 升主判据；**这是跑数前估算拦下的白跑**——R36-C5/
R37-C5/R39 a1a2/R37 b1 都是跑完才发现功效不足（owner review #2）。

**修订（2026-10-10，v0.330，owner review #3）**：`power_mde` 公式拆
**ρ_pair**（配对相关——同信号两变体，越高 SE 越小）/ **deff**（日簇
设计效应——同日市场冲击把有效样本数打折，越高 SE 越大）：原式把两个
**方向相反**的相关混成一个 ρ 且缺 deff 项 ⇒ 本表 MDE 均为**低估**
（真实 MDE 只会更大）；采 A 的方向性结论（相邻档差检测不到、C3 升
主判据）不受影响且更稳。上表 ρ 列应读作 ρ_pair、deff=1.0（无日簇
效应下界）；实测 deff = 日簇 bootstrap SE² ÷ iid SE²（待 R37-C5 v3
读数回填后更新本表）。

**修订（2026-10-10，v0.335，owner review——跑数前）**：上表输入取自
R37 战役 n_taken≈133/档——那是 **top-N 组合口径**；本单元实际用
**collect_all 全候选分档**，笔数大得多，但交易成簇（C4 修订同因）⇒
**有效 n = 簇数**而非笔数，口径不可直接平移。方法论随之修订：MDE 的
n 一律按簇数计、deff 取**簇设计效应**（沿用 v0.332 拆出的 deff 算法，
日簇换成信号簇：实测 = 簇 bootstrap SE² ÷ iid SE²）。本机无生产数据，
**实际簇数待发令前由生产机一探回填本表**（跑数前待办，合规——回填
后若 MDE 形态变了（如 C3 不再是最灵敏判据），判读条款不变、判读
权重按新表打折）。

### 判据（跑数前写死）

- **R42-C1（样本量）**：每档每窗 n ≥ 50（collect_all 口径下判定窗每档
  ~130+ 笔，门槛有余量）；**不过 ⇒ untested 不判 falsified**。
  **修订（2026-10-10，v0.335，owner review——跑数前）**：n ≥ 50 数的是
  成簇交易**笔数**，有效样本远少（同票连续信号同档同结局）；阈值不变，
  但每档每窗**簇数入报告**（`n_clusters`）供判读打折——有效 n ≈ 簇数
  （见功效节修订段）；
- **R42-C2（单调性，硬前提）**：双窗都满足 margin(高) ≥ margin(中) ≥
  margin(低) **且** 高−低 > 0。**打平读法写死**：按字面「≥」——
  「高=中>低」算过（只要高−低>0），「高>中=低」也算过；任何一处
  倒挂（<）即不过。C2 不过 ⇒ **falsified 当场收口**，C3 起不再启动。
  **MDE 判读条款（v0.326 采 A）**：C2 问的是**符号序**、不指定量级，
  MDE 不改变判定本身，但**判读纪律写死**——相邻档差 |Δ| < MDE
  （ρ=0.5, n≈133）≈ **0.086** 时，单调「成立/不成立」都按**低置信**
  处理（形态读数非结论：假顺序和真顺序在这个 n 下都认不出）；
- **R42-C3（仓位增量，问法本体+主判据）**：指标 = **加权 expectancy_R
  （Σw·R/Σw）对比等权**（owner 2026-10-09 更正：margin 是逐笔不加权
  量——胜率−盈亏平衡胜率——按档调仓位改变不了它，原方案「对比等
  仓位 Δmargin」会恒等于 0，作废）。**v0.326 起 C3 为主判据**
  （MDE(ρ=0.75, n=400)≈**0.035**——本设计最灵敏的判据，见功效节）。
  **MDE 判读条款（写死）**：任一组双窗 |ΔexpR| < MDE ⇒ 按**「与零
  无法区分」**判读（不读成增量、也不读成证伪）；|Δ| ≥ MDE 才按
  符号判读。**权重格 3 组事先写死不搜索**，每组归一化到**平均权重
  =1**（总敞口与等权基准一致——Δ 不被敞口驱动，这正是 rdd 门要防
  的情形，归一化从结构上控制）：

  | 组 | 原始权重 {高,中,低} | 归一化后 | 机制 |
  |---|---|---|---|
  | W1 | 1.5 / 1.0 / 0.5 | 1.50 / 1.00 / 0.50 | 线性倾斜 |
  | W2 | 2.0 / 1.0 / 0.0 | 2.00 / 1.00 / 0.00 | 强倾斜（低档不做） |
  | W3 | 1.5 / 1.0 / 1.0 | 1.29 / 0.86 / 0.86 | 只加码高档 |

  ⚠️ **W2 低档权重 0 = R36 Phase 4 已证伪的过滤器路线**——保留它
  是做对照，读数时必须注明（过滤器证伪 v0.292 在案）。判定：任一组
  双窗加权 expR > 等权 ⇒ 过。
  **组合层未测（写死）**：组合层加权 rdd + v2.1 相对门（参照=等仓位）
  需要逐笔仓位权重——2026-10-09 核实 `simulate_portfolio_topn` 仓位
  是固定 risk_pct 制、**不支持逐笔权重**；按 owner 拍板**不改引擎**，
  本单元 C3 只报交易层加权 expR，组合层标注「未测」（引擎支持后补测
  属新单元）。
- **R42-C4（随机对照/多重比较记账）**：保持各档样本数不变、**打乱
  「交易→档」归属**，N=50 臂；每臂取同一套权重格的 max（与 C3 同
  预算）；C3 最佳组 > 池 q95；池 ≥50 才 confirmed，未满 provisional
  不停（v0.266/v0.297/v0.299 判据族沿用）。
  **修订（2026-10-10，v0.335，owner review——跑数前）**：打乱粒度从
  逐笔改**整簇**——collect_all 口径下交易成簇（同一只票连续几天出
  信号、分数相近、落同档、出场结果几乎一样），逐笔打乱把簇拆散，
  零假设下方差被低估、q95 系统性偏低（owner 用本终端
  window_readings/weighted_expr + kit 池构造做零假设模拟：结局与分数
  无关、40 种子——簇大小 1 ⇒ confirmed_pass 1/40=2%；**簇大小 20 ⇒
  15/40=38%**（名义 ≈5%）；与 v0.324 bootstrap 改日簇是同一个问题）。
  簇定义写死：**同 code、信号点相邻（间隔 ≤ 持有期或 ≤5 根 bar）的
  连续段**（相邻判定用 bar 序号 i——同 code 内 i 单调；缺 i 退回日期
  差——单源 `criteria_kit.cluster_ids`）；臂构造 = 每簇**独立均匀抽
  一档**（`criteria_kit.cluster_draw` 单源），同簇交易同档，各档笔数
  组成在臂间**自然波动**——这正是零假设该含的方差，不再强行对齐
  笔数；
- **R42-C5（终审）**：pre2019 untouched 段（2010-2016）单独终步，

### 写死的风险注记（判读时逐条核对）

1. **先验偏低（写死）**：R36 排序器路线与过滤器路线均已证伪，分层
   本质是粗排序再乘仓位——C2 判负是大概率、是合法结局（维持
   candidate 现状），判正需 C4/C5 双保险；
2. **分档切点的选择效应**：切点估自挖掘窗是双窗纪律允许的唯一
   数据驱动；换窗切点漂移的敏感性由 C2 双窗同要承担；
3. **组合层未测的边界**：C3 的增量是交易层口径，仓位倾斜在组合层
   （资金曲线/回撤）的净效应本单元给不出——判读时不得把交易层
   增量直接外推成组合层结论；
4. **W2 对照读法**：W2 若「过线」而 W1/W3 不过，读作「过滤器效应
   残存」而非「分层成立」——报告里 W2 单列对照段，不与分层结论
   混读。
