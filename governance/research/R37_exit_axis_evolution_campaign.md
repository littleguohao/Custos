### Phase 0 · 出场轴现状审计（✅ 2026-09-23 代码审计，本页落档）

回测侧唯一交易级引擎 `simulate_b1_trade`（`src/custos/research/
backtest_factors.py:2876`）出场规则清单：初始止损（low/pct/platform 三模式）

三方对齐（simulate 形参 == strategy_grid.EXIT_PARAM_FLAGS == EXIT_RULES.json
params），信号/出场解耦（`--signals-out/--from-signals` 重放
1420ms→131ms/方案）——**出场变体重放便宜，是出场轴批量寻优的经济性基础**。

审计关键发现——**两侧规则集不对称**：

- **回测有、live 未接线**：breakeven/trailing/time_stop/cost_zone_flat 在
  simulate 里完整实现且经 R9/R10 回测，但 live EXIT_RULES 恒 enabled=False

  实现进 simulate = 新出场机制 = 语义变更，**不在本单元 Phase 1 范围**
  （单独立项候选，见非目标）。

已在案的警示（本单元判据的直接来源）：

### 方法论纪律（跑数前写死）

1. **入场钉死**：V0 等权骨架 + j_low 基底信号，入场侧一个字不动——Δ 只

2. Phase 1 **不引入新出场机制**（新机制 = 语义变更，单独立项 + 回测）；
3. 判据跑数前写死；多重比较显式记账（台账逐批记录评估数与随机臂读数）；

### 战役壳设计（写死）

- **内层批次**：evolution_loop 跑一批出场基因组。**基因组 = 机制开关 ×
  参数档位**（合法空间 = simulate_b1_trade 现有参数：stop_mode/stop_pct/
  stop_buffer/breakeven_trigger/trail_pct/scale_out_frac/bbi_exit_consec/
  qsx_exit_consec/cost_zone_bars/cost_zone_pct/time_stop_bars/stop_trigger
  及其 on/off）；**变异算子规则化**（参数扰动 / 开关翻转 / 档位迁移），
  非 LLM；
- **外层确定性控制器（CTL 规则，机械执行）**：
  - **CTL-1 继续**：批 top Δmargin（vs 基准档）相对上批改善 ⇒ 同家族
    继续下一批；
  - **CTL-2 转向**：某机制家族（trail / breakeven / scale_out / cost_zone /
    qsx / time_stop）全部变体**连续 2 批** Δmargin ≤ 0 ⇒ 该家族关闭
    （台账记死刑），剩余家族继续；
  - **CTL-3 证伪停**：**连续 3 批**无候选过 C2，或全部家族关闭 ⇒ 出场
    参数路线证伪收口，结局②归档；
  - **CTL-4 过线停（v0.269 两段式）**：任一候选过 C2+C3+C4 ⇒ 池
    ≥ c4_min_pool（100）则 confirmed——战役暂停，candidate 注册，C5 终审
    单独终步（一票否决链）；**池未满只记 provisional（宣告不停战役）**，
    池满后对全部 provisional 机械终判（冻结 objective vs 当前 q95——
    评估确定性 ⇒ 读数不重算只重比），胜出才 confirmed。**C5 pre2019 是
    一次性底牌，不许烧在早批侥幸上**（owner review：池=8 时 q95≈max，
    零假设过线率实测 13.76% = ~5% 的 2.7 倍）；
  - **CTL-5 预算帽**：总基因组评估数 ≤ 500，逐批记账——多重比较显式化，
    防「跑到出正为止」；
  - （CTL 数值为建议值，owner 跑数前可修订一次；跑数启动后一字不动。）
  - **检查次序（写死，v0.265 钉入）**：CTL-4 > CTL-2 > CTL-3 > CTL-5 >
    CTL-1——**次序即语义**：CTL-3 含「或全部家族关闭」，必须 CTL-2 先跑，
    家族团灭的一批才能同批触发证伪（而不是白跑一批空家族）；
- **台账 JSON 契约**：每批记录 {batch_id, 家族开关态, genome 数, top 基因组
  与读数, 随机臂读数, 家族死刑记录}——合并随机分布与 95% 分位逐批记账；
- **随机出场臂**：与进化臂**同空间**的随机参数组合，每批随行（逐批派生
  种子，非固定——R36 固定种子重言式教训）。**出场轴的随机标尺自备**——
  入场侧 +0.5474/+0.5476 是打分基因组读数，不能沿用。

## 附录 · C3 零假设通过率反推（生产机零算力，v0.274 修订版）

```bash
uv run python - <<'PY'
import json
doc = json.load(open(
    'artifacts/logs/exit_campaign/r37_b1/campaign_ledger.json', encoding='utf-8'))

final = {}          # key → 终态分类（只用于 k 与双过观测，不用于 p̂）
trials = passes = 0  # C3 试验全量计数：每批扰动抽样独立（_batch_rng）⇒
# 每次裁决都是一次独立 C3 试验；p̂ 用全量试验，k 用去重基因组——两个计数器
# 分开（owner review：去重取末次会把批1 的 c3_fail 被批2 覆盖、且顺序依赖）
for b in doc['batches']:
    for a in b['ctl_actions']:
        t = a['type']
        if t == 'near_miss':
            ok = a['why'] != 'c3_flipped'
            final[a['key']] = 'c3_fail' if not ok else 'c4_fail'
            trials += 1
            passes += ok
        elif t == 'provisional_candidate':
            final[a['key']] = 'c4_pending'
            trials += 1  # 宣告 = 一次 C3 试验（过）；池满终判不重抽 ⇒ 无新试验
            passes += 1
        elif t == 'candidate_found' and not a.get('confirmed_from_provisional'):
            final[a['key']] = 'pass'
            trials += 1
            passes += 1
for p in doc['state']['provisional_candidates']:
    # 终态只落 final（k/双过观测用）；其 C3 试验在宣告时已计，不重复
    final[p['key']] = {'confirmed': 'pass', 'expired': 'c4_fail',
                       'pending': 'c4_pending'}[p['status']]

k = len(final)  # 独立基因组数（多重比较计数；批内 seen+局部变异 ⇒
# 同 key 跨批重复裁决，裁决次数≠独立检验数；空间 218,400 vs 评估 360）
p_hat = passes / trials if trials else float('nan')
fp_owner = 1 - (1 - 0.05 * p_hat) ** k if k else float('nan')
both = sum(v == 'pass' for v in final.values())
print(f'C3 试验 {trials} 次（过 {passes}，p̂={p_hat:.3f}）；'
      f'独立基因组 k={k}；双过 {both}（观测值，含真阳性）')
print(f'战役层假过线估计 1−(1−0.05·p̂)^k = {fp_owner:.1%}')
PY
```

读法（写死，v0.272/v0.274 修订在案）：
- **p̂ 用全部 C3 试验**（每批扰动抽样由 _batch_rng 派生、相互独立 ⇒
  每次裁决是一次试验，样本量最大且**顺序无关**）；**k 用去重后的
  独立基因组数**（多重比较计数）——两个计数器分开（v0.274，owner
  review：v0.272 共用去重集合，为修 k 的独立性牺牲了 p̂ 的样本量，
  且批序覆盖使 p̂ 顺序依赖、偏向任意）；
- **provisional 按终态计一次**（confirmed/expired/pending 取自台账
  state；宣告时其 C3 试验计入 trials，终判不重抽不产生新试验——
  expired 不漏算、confirmed_from_provisional 不双计）；
- **已删退化行** `1−(1−f̂)^k`：both=1 时恒 = 1−1/e ≈ 63.2%（与数据
  无关的数学恒等式），且「观测过线率」≠「假过线率」（范畴错误）；
  双过数只作观测值印出，不进公式；
- p̂ = 「C2 过线者中 C3 通过率」——C2 已富集，非严格零假设（near_miss
  主体是近似零假设群，现有最好经验估计，局限注记）；
- fp_owner 的独立性假设也只**近似**成立（去重缓解但未消——同邻域
  基因组结果相关）⇒ 读数一律按**上界**用；此前引用的 53.7%（15 次
  裁决）同样是上界性质，不是精确值（owner 自述在案）。
两个数贴回来 ⇒ 决定 candidate_found 的可信度与 C5 是否值得动。
