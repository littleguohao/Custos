## 主题

0AMV 状态机（单日 >+4% ⇒ 做多，单日 <−2.3% ⇒ 空头，其间粘滞）的行为画像：一段做多 / 空头里 0AMV 与指数
通常走多远、多久；翻转后多快翻回（「反复」）、在什么位置更容易反复；以及把「连续 2 个交易日合计 >4%」
也算作翻多信号，这类翻多和现行单日 >4% 翻多的质量是否差不多。

## 目标

1. **①段内幅度与持续**：每段做多 / 空头的持续天数、段内 0AMV 与上证指数（999999）的最大顺向幅度、
   最大逆向幅度、段末累计幅度，报分位数（p10/p25/p50/p75/p90）。
2. **②④翻转后反复**：空翻多（④多翻空）后 5 / 10 / 20 个交易日内翻回的比例。
3. **③反复位置**：按翻转日位置分层报 10 日反复率。分层事先固定：
   - 指数位置：空翻多按「收盘距前 60 日最低收盘涨幅」分 <5% / 5~10% / 10~20% / ≥20%；多翻空按「距前 60 日
     最高收盘跌幅」分 >−5% / −5~−10% / −10~−20% / ≤−20%；
   - 0AMV 位置（需日增量）：翻转前那段反向状态里 0AMV 的段内累计幅度（前段首日到翻转前一日）。空翻多看前段（空头段）跌幅，按 >−5% / −5~−10% / −10~−20% / ≤−20% 分档；多翻空看前段（做多段）涨幅，按 <5% / 5~10% / 10~20% / ≥20% 分档；
   - 触发强度（需日增量）：翻转当日 0AMV 增量，空翻多 4~5% / 5~7% / ≥7%，多翻空 −2.3~−3% / −3~−5% / ≤−5%。
4. **⑤连续 2 日合计 >4% 变体（S1）**：S1 = 现行状态机（S0）+ 新增翻多条件「当日与前一交易日 0AMV 增量均 >0
   且两日合计 >4%」（空头条件不变；两日须为相邻交易日，均为 confirmed 读数）。S1 的翻多按触发方式分
   「单日型」（当日 >4%）与「两日型」（只满足新条件），比较两类的质量。

## 证据与过程

### 窗口与口径（跑数前写死）

- **只读挖掘 A（2000~2016）∪ B（2022~2026-09-04）**，`load_window.mining_violation` 校验；判定段 2017~2021
  与 holdout 不出任何读数，不登记 window_usage。
- **状态重放**：从台账首日起按 S0 / S1 全程重放再截取（同 `load_amv_regime` 口径，避免起点重置为中性）；
  判定段的读数只用于把状态延续到挖掘 B 起点（同 v2 段前预热，只读不报）。
- **事件**：翻转日 ∈ 段内才计；段 = 翻转日起到下次翻转前一日。段走出挖掘段末 ⇒ 截尾（`censored`），
  持续与段末幅度只用未截尾段，最大幅度用段内已见部分并单报截尾数。
- **前视窗**：N 日反复率 / 前向收益的窗口越过段末 ⇒ 该事件对该 N 不计（防读入判定段 / holdout）。
- **0AMV 水平**：由逐日增量连乘还原（相对水平，起点任意）；指数用上证收盘。
- **幅度**：做多段 顺向 = 段内最高 / 翻转日收盘 − 1，逆向 = 段内最低 / 翻转日收盘 − 1；空头段反之。

### ⑤ 判据（跑数前写死）

在挖掘 A、B **各自**计算 S1 的两日型翻多与单日型翻多：

- (a) **反复**：两日型 10 日翻回率 − 单日型 10 日翻回率 ≤ +10pp；
- (b) **前向**：两日型翻多日后 20 日上证收益均值 ≥ 单日型均值 − 1.0pp；
- (c) **样本**：两日型事件 ≥10 个。

A、B 都满足 (a)(b)(c) ⇒ **等效**；任一段 (c) 不满足 ⇒ **证据不足**；其余 ⇒ **不等效**。差值的 95% 区间用事件级
bootstrap（2000 次，seed 0）报，只作描述，不进判定。附报（描述）：S1 相对 S0 多出的做多日数、这些日子的
次日上证收益均值 vs S0 做多日均值；两日型翻多比 S0 提前的交易日数（S0 在同一段内也翻多时）及「S0 整段未翻多」
的占比。

**⑤ 的定位**：只回答「两日合计 >4% 和单日 >4% 效果是否差不多」。即便「等效」，改状态机仍是全链语义变更，
须另立单元（叠 B1 的 R4 口径组合读数）并走判定段批次，本单元不给「改不改」。
