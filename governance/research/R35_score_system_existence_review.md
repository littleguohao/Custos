## 主题

打分系重建五轮全灭（R22 变体 / R24 校准 / R29 稳定 / R30 组合搜索四轮**旧轴
调权**，+ R34 新轴基因组双来源 C4 打不过随机臂 +0.5474）。R34 回填的决议已
写明：转元层反思——**不再做第六轮参数/轴寻优**，而是检讨**打分系统
（八段技术分 × A/B/C/D 分层）这个形态本身该不该存在、该以什么角色存在**。

## 目标

回答一个问题：**现行「八段技术分 → 强/中/弱 → 共振矩阵 → A/B/C/D 分层 →
buy_review/observe/track/avoid」这条形态链，在证据面前还能以什么角色继续
存在**？产出三终局候选的定义、各自改动面、与既有证据的兼容性，以及
owner 拍板前必须回答的问题清单。

## 结论

**📋 开题，尚无终局（2026-09-16 落档）。** 本页按 R12 纪律先把五轮证伪总账
与三终局候选写死，不动 live 现行任何一行代码。三个终局——A 维持 V0 定性为
粗过滤、B 简化腿数只留有独立证据的腿、C 撤分改门（打分退役）——各自的含义、
改动面与证据兼容性已在案；owner 按「决策路径」节的问题清单拍板后，任何
终局的实施都是独立提交、独立验证（buy_review 消费链不在这页改）。

### 现行分层消费方式（从 pipeline 代码核实，非凭记忆）

- 技术分 = patterns 八段累加（s_shape 主路径 v0.50 已删，唯一口径），
  阈值 `TECH_STRONG_FALLBACK=60 / TECH_MID_FALLBACK=30` 分强/中/弱
  （`score_candidates.py:135-136`）；
- 分层 = `RESONANCE_MATRIX`（技术 × 资金意图两轴）→ base bucket A/B/C/D
  （`score_candidates.py:88-101`），风控可再降档（`apply_risk_downgrades`）；
- 行动语义 = `NEXT_STEP`（`score_candidates.py:115-124`）：A=buy_review
  （**人工复核**——BuyPlan 契约已删，原 "generate_buy_plan" 是虚假承诺、
  零行动读者）、B=observe_price、C=long_term_track、D=avoid；
- 展示消费 = candidate_table：⭐ 信号一览「可买（A + 市场/基本面/技术三面
  共振）」、🐂 共振区、A/B/C/D 池明细、🔍 受限区（C/D）。
- **关键事实**：分层不产出任何自动买入计划——它的全部作用是给**人工复核**
  排序分组。这决定了三终局里「形态可以降级到多简」的下限。

### 三个候选终局

**A · 维持 V0 分层，定性为粗过滤。** 承认打分无 alpha，但分层是既有行动秩序
（人工复核的优先级队列），**不再投入任何优化**；打分纪律（调 weights 先
回测，同 cap_rules）保持。改动面 = 零（仅文档定性）。与证据兼容性：R19 无
预测力不影响「粗过滤队列」角色（队列排序错一点不伤筋动骨，反正人工复核）；
R2/R3 选股无 alpha 与「粗过滤」不冲突——只要不把它当 alpha 用。
风险：队列质量低 ⇒ 复核带宽浪费在 D/C 档里漏看真赢家（R3 召回瓶颈的
另一面——分错层的代价由人工兜）。

**B · 简化腿数。** 从八段砍到经五轮证伪洗礼后**仍有独立证据**的少数腿，
其余降 evidence_only。逐腿证据清点（初稿，拍板前须逐腿复核）：rsi_deep
（R20 画像四臂全稳 + R21 四档出场压基底 +26~+42pp，**唯一跨窗证据**，
已升 candidate）；j_low（基底恒真，不计分但承担进场触发——它不是腿是
基底）；其余六段（patterns 五单项/MACD 系/资金/出货减分等）的独立跨窗
证据**无**（R19 整体无预测力 ⇒ 单腿证据只能更弱）。改动面 = 权重表
（scoring.weights）+ 腿清单治理；纪律风险同 A 再加一条：砍腿后分层分布
漂移需要 ≥10 交易日影子观察。

**C · 撤分改门（打分退役）。** 取消分值分层，A/B/C/D 改由 **gate 布尔组合
+ 分位数分层**直接生成（R24 止血方案已是分位数——「撤分」只是把止血方案
扶正）。改动面最大：score_candidates 分层逻辑、RESONANCE_MATRIX/NEXT_STEP
消费点、candidate_table 展示语义全要重写；收益 = 彻底不再背「无 alpha 的
精确分值」这个伪精确负担（分值给人「60>30 有意义」的错觉，R19 已证没有）。
风险：gate 组合的判据又是新一轮寻优——**必须预注册**，否则就是第六轮回潮。

### 决策路径（每个终局需要的证据/拍板点）

- 选 A：owner 确认「粗过滤队列」角色可接受即可落地（纯文档定性）；
  拍板点 = 复核带宽与漏看代价是否容忍。
- 选 B：需逐腿证据清点复核（本页初稿逐腿重审）+ 砍腿后分层分布影子
  （≥10 交易日，可复用 #76 影子机制）；拍板点 = 保留腿清单。
- 选 C：需先答「分位数分层的档距怎么定」（R24 止血方案的既有档距在案）
  + gate 组合预注册；拍板点 = 是否接受打分系统正式退役及其文档考古成本
  （STRATEGY_REGISTRY/治理文档大批同步）。

### owner 需要回答的问题清单

1. **分层在 daily 决策里实际被怎么使用？**（已核：仅人工复核的分组/优先级，
   无自动买入计划——见「现行分层消费方式」节；owner 确认是否与实际工作流一致）
2. A/B 档候选被买入的比例 vs C/D 档被买入的比例（人工复核的实际分布——
   若 C/D 档实际也常被买，分层的「队列」角色都名不副实，A 也不成立）；
3. 复核带宽：每日 A+B 档平均多少只、人工能看多少只（决定队列截断点该不该
   存在，以及 A 终局下要不要收紧 A 档）；
4. 若选 B：除 rsi_deep 外，owner 是否认可「其余六段无独立跨窗证据」的
   清点结论（要逐腿点名还是整体降 evidence）；
5. 若选 C：分位数分层的档距沿用 R24 止血方案还是重定（重定=预注册）。
