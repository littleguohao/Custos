## 主题

止损口径与出场机制能否改善结果

## 目标

找出可用的止损配置

## 结论

**① 止损判定「盘中 → 收盘」是最大单项改进**（来自 R16 材料纠偏）。口径修正的贡献可以精确隔离；组合级从 **−23% 转正到 +17%**，且风险调整后差异巨大。第一轮「trail/be 砍掉趋势单」的结论在收盘口径下**不成立**。

**② 5% 是止损下界的「崖」不是「坡」** —— 5%→4% 掉 **42%**，而 5%→12% 只是平移。
⇒ **本轮最强的单一结论：B1 的止损普遍太紧。**

**③ `tick_buffer` 最优在 3 附近**，5 以上反而不如基准 —— 但**该参数本身设计有问题**。

**④ `cost_zone_stop` 在择时上下文里有效**（把大亏 −14.23% 截成 −4.40%，盈亏比 2.653 B组最高），而**同一个参数在 A 组是 ❌**（累计R −22.5%）⇒ **机制不能单独评价，得看它和谁搭配。**

**⚠️⚠️ 以上全部相对判定的「基准盘」几乎为零 —— 见 R11。**
不是「相对判定错了」，而是基准本身没有边际，+43% 的相对改善也无从产生可用策略。
⇒ 提法要换：不再问「能把 +0.39% 提升多少」，而问「**有没有方案能在 3000 只宇宙里做出 >3pp 的 margin**」。

## 下一轮：机制类改进（M2，2026-08-04 起）

### 为什么转向机制

H1/H2 终审的总账是「**本轮无一通过跨窗终审，死法相同：edge 集中在 2025-2026 单一
regime**」。而同期唯一验证成功的改动是**分批止盈**——它不预测涨跌、只改出场，所以没有
regime 依赖的风险：胜率 18.0% 一位小数没动，期望 +16%、累计 R +10%。

这两件事指向同一个结论：**排序类因子这条路暂时走到头了**（瓶颈在召回不在排序，
且任何"更严的入场条件"都要先过跨区间），而机制类改进（出场/仓位）是可控的。

机制类改进天然更稳健，原因不在于"运气好"，而在于它**不含对未来方向的预测**。移动止损
不需要知道明天涨还是跌，它只在价格已经回撤时执行；因子必须预测，所以才会有 regime 依赖。

### 本轮新实现的两个机制

**① 盈亏平衡保护（`--breakeven`）** —— 又一处「文档定义了但回测没实现」：
`01_swing_rules.md:328`「已形成有效浮盈后，同时启用盈亏平衡保护，防止赢转亏」。
浮盈达阈值后止损上移到成本价。构造场景实测：同一段"涨到 +12% 后跌回"的走势，
无保护 **−1.00%** → 保本 **0.00%** → 移动止损 **+3.96%**。

**② 移动止损（`--trail`）** —— 止损跟随持仓期最高价，回撤给定比例出场。

两者都**默认关闭**（0=不启用），保证历史结果可对照。

⚠️ **都只用截至前一根的最高价更新止损位**，再用当日 low 判触发。日线数据不知道盘中顺序，
若用当日 high 更新止损再用当日 low 判触发，等于假设"先冲高后回落"——这是乐观的未来函数。
`tests/test_stop_mechanisms.py::TestNoLookAhead` 钉住：构造"当日冲高 +15% 后收跌"的 K 线，
断言不得在当日触发（11.5×0.92=10.58 > 当日 low 9.85，有未来函数就会命中）。

### ⚠️ 移动止损的主要风险：可能砍掉大赢家

终审揭示的收益分布是**极端幂律**——若总 1000 笔，24 笔（2.4%）均收 +36.23%，
其余 976 笔平均 −0.45%。移动止损保护的是回撤，但**代价可能是把趋势单提前砍断**，
而那些趋势单是全部收益的来源。所以本轮必须**同时看 `payoff_ratio` 和大赢家数量**：

> 判定标准（**2026-08-04 修正，见文末「M2 首轮判读的两个口径错误」**）：
> 组内（同一 `stop_mode`）比 `expectancy_R` 提升 >2%、`avg_win` 跌幅 <5%、
> 大赢家**占比**不下降；跨 `stop_mode` **只比收益率**（`expectancy`/`win_rate`/
> `payoff_ratio`/盈亏平衡 margin）；组合级只比 `total_return`/CAGR/`max_drawdown`。

已有测试钉住"无回撤的单边上涨不得触发"（`test_does_not_cut_trend_without_pullback`），
但真实数据里回撤总会有，所以这条只能靠回测判。

### 回测命令（`S=src/custos/research/backtest_factors.py`，全部带 `--trade-sim`）

```bash

# ② 保本止损扫描——文档定义的机制，先验证它值不值得
uv run python $S $B $U --breakeven 0.03
uv run python $S $B $U --breakeven 0.05
uv run python $S $B $U --breakeven 0.08

# ③ 移动止损扫描——注意看 avg_win 与大赢家笔数有没有被削
uv run python $S $B $U --trail 0.08
uv run python $S $B $U --trail 0.12
uv run python $S $B $U --trail 0.18

# ④ 组合（只在 ②③ 各自有效时才跑）

#    'pct'=固定百分比(空间可控,R 口径更干净)
uv run python $S $B $U --stop-mode pct --stop-pct 5
```

## M2 第二轮（300 样本，收盘止损口径）——止损口径是最大单项改进

owner 跑完 25 个方案。**结论与第一轮几乎全部相反**，原因不在样本量，在**止损触发口径**
（第一轮是盘中，本轮默认已按 B1_w.pdf 改成收盘）。

### 口径修正的贡献可以精确隔离

本轮里 `trigger_intraday` 就是旧口径的对照组，它的胜率 19.2% 与第一轮基准 18.0%
几乎一致 ⇒ 两轮口径可对齐。同一批样本内、唯一变量是触发口径：

| | 盘中（旧） | 收盘（新） | 倍数 |
|---|---|---|---|
| 胜率 | 19.2% | **36.3%** | 1.89× |
| 期望R | +0.184 | **+0.624** | **3.39×** |
| 累计R | +76 | **+245** | 3.22× |

**这是目前所有改动里最大的单项提升**，来自材料的「设止损…看收盘价」
「破掉止损价格，拍掉！（收盘时）」「忽略盘中的冲高回落」。
机制上很直白：B1 是超卖贴低进场，`risk_frac` 中位仅 0.65%，盘中假破几乎必然发生。

### 第一轮「trail/be 砍掉趋势单」的结论在收盘口径下不成立

```
第一轮（盘中口径）：trail 越松越好 0.18 > 0.12 > 0.08，趋向「无 trail」=基准 ⇒ 全否决
本轮（收盘口径）：  trail_08 +0.769 > trail_12 +0.746 > trail_18 +0.686 > 基准 +0.624
```

**排序完全翻转。** 盘中口径下 trail 被假破频繁触发（它跟随最高价，止损位更高、更易被扫），
收盘口径下才真正起到保护作用。

⇒ **机制的效果依赖第三个参数（触发口径）**。第一轮的结论不是错，是在错的口径下测的。
这也是个通用教训：否决一个机制之前，先确认它依赖的基础设施口径是对的。

### ⚠️ 择时方案的样本量不足，数字不可采信

`--amv-long-only` 把样本砍到 1/5.5（0AMV 做多期只占约 18% 的时间）：

| 方案 | 笔数 | 胜率 | 95% CI（Wilson） | 区间宽度 |
|---|---|---|---|---|
| 基准 | 410 | 36.3% | [31.8%, 41.1%] | 9.3pp |
| `amv_long_only` | **75** | 34.7% | [24.9%, 45.9%] | **21.1pp** |
| `pct_08_amv` | **69** | 52.2% | [40.6%, 63.5%] | **22.9pp** |
| `pct_12_amv` | **68** | 51.5% | [39.8%, 62.9%] | **23.1pp** |

`amv_long_only` 的「期望R +2.113」看着惊人，但 75 笔的置信区间宽达 21pp，
**不足以支撑任何结论**。要么加大样本，要么延长区间。

### 组合级从 −23% 转正到 +17%，且风险调整后差异巨大

| 方案 | 敞口 | 总收益 | 回撤 | **收益/回撤** |
|---|---|---|---|---|
| `pf_top2_c2_amv` | 40% | +17.1% | **2.9%** | **5.94** |
| `pf_top3_c5_p05_amv` | 25% | +15.8% | 3.4% | 4.68 |
| `pf_c5_p05_amv` | 25% | +12.6% | 4.4% | 2.84 |
| `pf_c2_p20` | 40% | +13.4% | 6.2% | 2.18 |
| `pf_c3_p20` | 60% | **+21.5%** | 14.1% | 1.53 |
| `pf_c5_p20` | 100% | +9.0% | 11.4% | 0.79 |

`pf_c3_p20` 总收益最高但回撤 14.1%；`pf_top2_c2_amv` 收益略低而回撤只有 **2.9%**，
风险调整后明显最优。**只看总收益会选错**。

与第一轮（1000 样本，−23.4%/−30.2%）相比，转正来自四个因素叠加：
收盘止损口径 + 0AMV 择时 + top-N 横截面择优 + 低敞口。这正面验证了受控实验的预测
（「决定因素是总敞口」「先到先得等于抽签」）。

### `cost_zone_3` 被否决 → 已按材料改判据（owner 2026-08-04 拍板）

第一版胜率 38.5%（全场最高）却期望R +0.557 < 基准 +0.624，均盈 9.76%（全场最低）——
典型的「砍掉慢热单」。根因是判据只有一条「未脱离成本区 3%」，把**已站上 BBI、
收盘价重心上行、只是涨幅还没到 3%** 的票也误杀了，而这类票里有后来的大赢家。

改为**三个维度都平淡才砍**，三条都直接对应材料原文：

| 维度 | 材料原文 |
|---|---|
| 未站上 BBI | 「不温不火，**没上BBI**，又没到止损。收盘前全拍！」 |
| 收盘价重心未上升 | 「一等马（**收盘价重心上升**为主）⇒ 拿住不动」<br>「看每天的收盘价是否还在提高！只要还在提高就不要怕！」 |
| 未脱离成本区 | 「三个交易日还没**脱离成本区**，又没打止损，多等一天」 |

任一维度显示还在涨就留着。构造场景实测：

| 场景 | 新判据 | 旧判据 |
|---|---|---|
| 贴 BBI 横盘（三维度都平淡） | ✂ 拍掉 | ✂ 拍掉 |
| 站上 BBI 但只涨 1.2% | **留着** | ✂ 误杀 |
| 重心上移但未站 BBI | **留着** | ✂ 误杀 |
| 已涨 3.5% | 留着 | 留着 |

两处实现细节值得记：

- **「重心」用前后段均值比，不用「末值 > 首值」**。重心是中枢概念，末值比较会被
  最后一根噪声左右（一根小阴线就把「重心上升」判成否），而那正是材料反复告诫的
  「忽略盘中/单日波动」。已用测试钉住一个「末值低于首值但重心明显上移」的序列。
- **「站上 BBI」必须用严格 `>`**。第一版写 `>=`，导致贴着 BBI 横盘被判成「站上」
  ⇒ 永不触发（构造场景①因此没被拍掉）。这也与既有 BBI 退出逻辑一致——
  那里对「相等」同样按中性处理（既不算站上也不算跌破）。

## M2 第三轮（1000 样本，新判据）——第一份可用的结论（2026-08-05 晚）

`--report-only` 用新判据重判了 25 个方案（逐笔 JSON 齐全，无需重跑）。

### 判据修正在这份数据里的实际影响

- **`trigger_intraday` 原先被误判成入场类**：1359/1294 = **+5.02%**，差 0.02pp 越过
  旧的 5% 线，于是一个纯出场机制（`--stop-trigger`）被当成入场类判。
  ⇒ 按笔数分类会失效，这条实测坐实了。（该方案两种判法都是 ❌，累计R -79.2%。）
- **`pct_05` 由 ❌ 翻 ✅**：换中间档 `pct_08` 作基准后，累计R **+73.8%**、

  当基准」把它掩盖成「入场类 + 削大赢家」。`pct_12` 现在是 ❌（累计R -36.3%）。
- A 组其余判定不变。

### B 组：`pct_05` 最优，且与 A 组的关系要注意

组内排序（基准 `pct_08`）：`pct_05` 累计R 157.5 > `pct_08` 90.6 > `pct_12` 57.7。
**止损越紧越好**这一条在 5%~12% 区间单调，说明下界还没探到 ⇒ 值得补 `pct_03` / `pct_04`。
但跨组表显示 B 组三档的 margin 只有 +3.1~+3.8pp，而 A 组 `trail_08` 也是 +3.8pp
——**收益率口径上两组打平**，B 组的优势在「止损可执行」（A 组 risk_frac 中位 0.65%
根本执行不了），不在期望收益。

### C 组：唯一确定的结论是「择时」，其余全是噪声

### 新判据当场救回一次

**`pct_03` 的累计R 159.7 是 B 组最高，期望% 却是最低。** 按旧判据它会以
「累计R +76%」通过并被当成最优档——那是分母 0.03 撑起来的（期望R = 期望% ÷ stop_pct）。
新判据判 ❌（期望% -39.1%、margin +3.3→+2.5pp 变薄）。上一节那个口径修正的实证。

### 5%→4% 掉 42%，而 5%→12% 只是平移

- 期望%：3% +0.39 / 4% +0.37 / **5% +0.67** / 8% +0.64 / 12% +0.63
- 5% 以上是**平台**（0.67/0.64/0.63，相差 ≤6%）；5% 以下是**崖**（-42%）。
- **成本解释不了**：成本固定 25bps，绝对值不随 stop_pct 变（变的只是它占风险的比例）。
- 真正的机制看**大赢家笔数**：**70 → 62 → 61**。收紧到 4% 以下开始打掉本来会赢的交易。
  配合 B 组基准的收益结构（尾部R +388 / 非尾部R -298），**砍掉 9 只大赢家足以抹平全部超额**。
- 侧证：止损越紧 → 胜率单调下降（44.6→41.4→38.0）而盈亏比单调上升（1.45→1.55→1.82）
  ⇒ 紧止损把赢家和输家一起提前砍掉，赢家那部分是净损失。

⇒ 修正我上一条「沿放宽方向继续探」的判断：**方向不是单调的**。`B1_w.pdf` 的
「向下 3-5 个价位」上界是对的，甚至 5 已经过头。`tick_buffer_5/8` 不必再往上探。

### 但这个参数本身设计有问题

`_TICK = 0.01` 是**固定金额**（backtest_factors:1196），所以 3 个价位：

- 5 元股 → 0.6%
- 10 元股 → 0.3%
- 50 元股 → 0.06%

**同一个参数在不同价位的股票上是完全不同的风险量。** 而 A 组 risk_frac 中位仅 0.65%，
这个量级的差异足以主导结果 ⇒ 它把「价格水平」这个无关维度混进了止损余量。
这也解释了为什么效果对 buffer 大小如此敏感、且在 3→5 之间就反转。

**更合理的做法是按百分比或 ATR 给余量**（例如「当日最低价 −0.3%」或「−0.2×ATR」），
让余量在不同价位的股票上是同一个风险单位。这是一条待做项。
