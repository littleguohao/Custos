## 主题

owner 2026-10-21：机构式多因子流程在实践中有效，B1 / B2 / 现行结果却推不出可用结论——是否缺了过滤条件？能否**逆向**看高盈亏比
那部分交易长什么样。R20 做过一次赢家画像，但它的赢家是「0AMV 区间收益 top10% / top50%」而非出场后的已实现交易，宇宙与窗口也是
旧口径。本单元在 R48 的交易集上（0AMV 做多 + J<13 × 现行出场，v2 全量 as-of 宇宙）把信号日能拿到的特征尽量铺宽，问：**哪些格子里
大单（≥ +20%）出现得更多、大亏没有同步放大，且这种现象在两个独立挖掘段都出现。**

同时回答一个具体疑点：机构流程的「均成交额 ≥ X 亿」流动性底线，我们的研究宇宙没有——低流动性票是否在拖累基底。

## 目标

产出一份「两窗复现的线索清单」（附整面板选择效应标尺）与一份流动性底线描述表，供后续单元预注册；本单元不做任何判决。

非目标（写死）：不判 candidate / falsified；不改 live；不搜阈值（格子切点写死）；不做 >2 阶组合；不上模型；线索不直接进第二批判定段读数。

## 结论

**📋 预注册定稿，尚无读数。**

- **机械判决**：无（探索单元）。产出 = `lead_robust`（两窗复现 + 过整面板 q95）/ `lead_replicated`（两窗复现未过 q95）/ `a_only` 三类格。
- **实质读数**：暂无。
- **不能读成什么**：①线索 ≠ 结论——`lead_robust` 也只是「值得预注册」，判定段终审才算数；②格子是挖掘段五分位切点，换窗切点会漂；
  ③流动性表是描述性，不是「加门槛就更好」的证明（加门槛改变宇宙，需另行预注册基线重测）；④幸存者宇宙（R14）会抬高小盘 / 低流动性格的大单率。

## 证据与过程

### 实验单元（写死）

- **交易集**：与 R48 完全相同（`tail_feature_study.run_study` 同次重放产物），只读挖掘 A（2000~2016）∪ B（2022~2026-09-04）。
- **结局**：大单 = 单笔已实现收益 ≥ +20%；大亏 = ≤ −10%。
- **面板（逐窗内分档）**：
  - 连续量：R43 as-of 特征矩阵 37 维、`s_shape` 分项（压缩 / 枢轴 / 量 / 口袋支点 / 套牢供给 / 均线结构 + S_shape / Δ / P / S**）、
    超卖原始量（RSI 当日值与近 5/10/20 日最低）、V0 分；每维两格 `@lo`（≤ 20 分位）与 `@hi`（≥ 80 分位）；
  - 布尔量：R20 因子命中面板（`winner_factor_study.build_factor_panel`，live 1800 链 as-of 同源）、R48 的 9 个二值特征、板块相位有利、
    周线 J 低 / RSI 底背离；每项两格（命中 / 不命中）。
  - 缺失不进该格统计。

### 流程与门槛（跑数前写死；零假设臂完全重复同一流程）

1. **A 合格**：`n_hi_A ≥ 1000` ∧ `lift_big_A > 1.2` ∧ `lift_big_A / lift_loss_A > 1`；
2. **二阶**：A 合格单格按 `lift_big_A` 取前 10，两两 AND 成 45 个对格，对格同样过 A 合格；
3. **B 复现**：同门槛在 B 窗（B 窗自己的切点）；线索统计量 = `min(lift_big_A, lift_big_B)`；
4. **选择效应标尺**：簇级置换（`tail_feature_study.cluster_perm`，两窗各自）N=200 臂，每臂统计量 = 复现格的 max 线索统计量（无复现记 0）；
   复现格统计量 > `kit.q95` ⇒ `lead_robust`。
5. **流动性描述块**：`amt20` ≥ 0 / 1 / 2 / 3 / 5 亿子集的笔数、占比、大单率、大亏率、均收益、胜率、盈亏比，两窗。

### 功效

- 交易量级同 R48（A ≈ 18.9 万 / B ≈ 38.1 万笔）；`@lo/@hi` 格约 20% ⇒ A 约 3.8 万笔，大单率 5% 下 lift 1.2 的 z ≈ 9（deff=5 时 ≈ 4）。
- 二阶对格约 4% ⇒ A 约 7,500 笔，同量级 z ≈ 2——二阶线索功效偏低，`n_hi ≥ 1000` 门槛保留，报告标注。

### 写死的风险注记

1. **多重比较**：面板约 150~200 格 + 45 对格，A 合格后 B 复现本身就是第一道防线，整面板 q95 是第二道；二者都过才是 `lead_robust`。
2. **R20 / R21 先验污染**：超卖类特征是旧窗口上发现的，挖掘段与旧窗口重叠 ⇒ 这些格的复现不算独立证据（判定段才算）。
3. **板块腿前视**、**PIT 起点 2014-04**、**幸存者宇宙**：同 R48 风险注记 2 / 4 / 5。
4. **高波动混杂**：大单与大亏同源于波动，`lift_big / lift_loss > 1` 门槛针对此；`vol60` 本身也在面板里，读线索时对照。
