## 主题

因子×出场交互（#81②，owner 2026-09-23 方法论五维度之①）：不问「这因子
能不能排序」，问「**这因子能不能告诉我该用哪套出场**」。R36（钉死出场问
排序，该口径证伪）与 R37（无因子问单一最优出场，1 untested + 2 证伪收口
换方向）两轴在本单元**第一次交叉**——因子不再用来排序选股，用来**分配
出场**；项目纪律「策略类研究以因子×止损×止盈三维搭配为实验单元」的真正
落地。与 R36/R37 的结论不互相翻案：C2 问的是**交互增量**，是三个不同问题。

## 目标

机械验证「条件出场分配」相对「单一最优出场」有没有可辩护的增量：条件规则
（因子连续值 × 分桶 × 映射 → 出场档）vs **uniform-best**（档集内单一最优档
应用于全部交易，选择同样只在挖掘窗——隔离「条件化增量」与「只是找到了更好
的单档」），双窗同向 + 灵敏度零翻转 + 随机分桶同预算对照。首个对象 =
信号日 ADX(14) 连续值。非目标（写死）：不动 live、不挖新因子、不重开
排序器问法、LLM 不碰数值、不做仓位轴。

## 结论

**⏸ Phase 2 判毕 untested（2026-10-09 r39_a2，v2.1 相对门口径首个真实
用例）**（模板 v0.321 起：机械判决 / 实质读数 / 不能读成什么 三栏）。

- **机械判决**：untested——C1 桶 0 n_taken=36/19 < 50（桶下限）不过，按
  v0.301 判 untested **不判证伪**（样本不足≠否定证据）；C3 4/4 翻转

- **实质读数**：top=B2[P2_fast,P2_fast] **退化=uniform-best 自身**（Δ≡0
  机械）；72 个非退化映射**无一双窗胜过** uniform-best（最佳 Δm+0.0031
  / Δj−0.0064 翻号——该映射按 pick_top 口径反推**未过 rdd 门**，否则

  **ADX(14) 分桶→出场档无条件化增量证据**；v2.1

## 证据与过程

### 背景：为什么是这个问法

- **R36**：因子 → 排序，出场全程钉死 pct5_trail08 ⇒ **该口径下的排序器
  路线证伪**（owner 定性：不是「方向死了」）；
- **R37**：出场 → 全群体**单一最优**，无因子条件 ⇒ 三战役 1 untested
  （r37_b1 存档备查不接 live）+ 2 证伪，收口签发**换方向**。

### 实验单元（写死）

**条件规则 =（因子 F 连续值，分桶 B，映射 M：桶 → 出场档）**。

- **主基准 = uniform-best**：同一档集内**单一最优档**应用于全部交易——
  隔离「条件化增量」与「只是找到了更好的单档」；uniform-best 的选择
  同样只在挖掘窗（与条件规则同搜索预算对账，谁也不多偷一眼）。
- **次基准 = pct5_trail08**（R34/R36/R37 终审同口径，跨研究可比；必报
  副读数，非判据线）。
- 入场钉死 V0 + j_low + 0AMV（同 R37：信号集与出场/分桶无关，信号缓存
  重放预热一次）；目标函数 v2 口径（margin 单量 + rdd≥1.0 约束门；
  只相对排序，引用连带 R11 声明）。

### 首对象（写死）：信号日 ADX(14) 连续值

- **机制假设**：强趋势 × j_low 深回调 = B1 自己的论点（R36 Phase 3 幸存
  单腿 adx_gt_60 的机制自洽在案）——强趋势标的修复动能足 ⇒ **高 ADX 桶
  配慢出场**（宽止损+慢 trail 让趋势奔跑），**低 ADX 桶配快出场**（窄
  止损+时间止损快抽身）。
- **因子定义**：信号日 Wilder ADX(14) 连续值，`indicators.dmi_arrays`
  单一实现（钉测与 `backtest_factors._adx_last` 末点逐位对账）；
  as-of 纪律同 V0 分（信号日时点，无未来数据）。
- **不用 0/1 布尔腿**：60 阈值本身从未被验证，连续值分桶不丢信息
  （布尔版 = k=2 且边界钉 60 的特例——列为灵敏度**副读数**，非判据）。
- R36 证据画像（背景非判据）：该腿在钉死出场下 C2 双窗同向
  （+0.0942/+0.1347 窗间增强）、C4 复审判毕死刑撤销（v0.286）、C5
  untested（CI 跨 0，n=376）——排序器口径「不可判」，本单元换问法重启。

### 出场档集（写死 K=4，机制象限策展）

| 档 | 基因组 | 象限 |
|---|---|---|
| P1 | sp5 + trail 0.08（=pct5_trail08 基准档） | 现行基准 |
| P2 | sp4 + time_stop 10（trail 关） | 快抽身 |
| P3 | sp8 + trail 0.15 | 慢趋势 |

双杀：13 连死 + 连死关闭互证）；全部在 R37 合法档位空间内
（`exit_genome.validate` 过）。

### 搜索（全枚举——无进化、无 LLM）

- **分桶**（分位点**只在挖掘窗估计**，判定窗直接应用，双窗隔离不破）：
  B2 = 挖掘窗中位数二分；B3 = 挖掘窗三分位；
- **映射**：每桶指派 P1..P4 ⇒ B2 16 格 / B3 64 格，**合计 80 格全枚举**；
- **top 选择**：挖掘窗 margin 最大（**v2.1 相对 rdd 门**：rdd(候选) ≥
  rdd(参照档 P1_base)，同窗同信号同口径——防偏袒高敞口的原意不变；参照档
  事先固定不经过挑选，uniform-best 不能当参照）；
- 出场重放 ~131ms/格 ⇒ 单窗枚举 ~10s，比 R37 进化战役便宜一个量级。

### 判据（跑数前写死；**v0.301 修订在案**）
