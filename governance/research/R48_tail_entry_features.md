## 主题

B1 基底（0AMV 做多 + J<13，现行出场）的盈利结构是「大量小赚小亏 + 少数大单」：R44 各档去掉收益最高的 1% 交易后期望≈0。
多信号加总排序（V0 技术分、配比寻优、加腿、过滤）已多次证明选不出好票。本单元换问法：**不排序，只问单个、事先指定、
有明确逻辑的入场特征，能否让「单笔 ≥ +20% 的大单」出现得更频繁，同时不让大亏同步变多。** 读出的东西用于后续仓位 / 持有研究
（命中特征的单子给更多仓位或更宽止盈），本单元本身不产生任何选股规则。

owner 2026-10-21 追问「1800 的多面共振能否参考」——live 四面共振是 市场 / 板块 / 基本面 / 技术 四条腿，「可买」= 市场 ∧ 基本面优 ∧ 技术强；基本面腿、技术腿、三面共振合取、四面共振腿数一并列入特征，
用同一口径复核（旧证据 v0.155 是 400 只抽样、旧窗口、margin 口径）。

## 目标

对 7 个特征逐个回答：在两段挖掘窗里，特征「高档」相对全体，大单命中率是否稳定提高、且大亏率没有同步放大、且打得过
「同样挑 7 个特征里最好的那个」的随机零假设。

非目标（写死）：不做组合打分、不搜特征、不调出场、不改 live；读数不升格为选股排序。

**📋 预注册定稿，尚无读数。**

## 证据与过程

### 实验单元（写死）

- **交易集**：0AMV 做多 + J<13 信号，信号日收盘入场，现行出场 `LIVE_PARAMS`（R44 参照档同口径），全量宇宙 as-of；
  每笔交易的结局只用已实现收益（剔 open_end / unfillable）。
- **大单** = 单笔收益 ≥ +20%；**大亏** = 单笔收益 ≤ −10%。
- **特征（7 个，信号日收盘 as-of，写死；R43 特征矩阵 / live `four_leg_resonance` 同源实现）**：
  1. `mcap_float` 流通市值（低档 = 小盘）——分五分位，检验「最低档」；
  2. `dist_high250` 距 250 日高点回撤深度——五分位，检验「回撤最深档」；
  3. `limitup60` 近 60 日涨停次数（题材活跃度）——分「≥1 次」vs「0 次」；
  4. `fund_good` 基本面腿：品质档 = 优（PIT，`fundamentals.detect` 同 live 口径；1800「可买」用的就是这一档）——二值；
  5. `tech_high` 技术腿：V0 技术分 ≥ 60（as-of，live `tech_level == 强` 同源）——二值；
  6. `resonance3` 三面共振 = 1800「可买」定义（市场 ∧ 基本面优 ∧ 技术强；市场腿 = 基底已钉 0AMV 做多 ⇒ 实际检验 4 ∧ 5）——二值；
  7. `legs_aligned` 四面共振腿数（owner 2026-10-21 追加）：live 四腿 = 市场 / 板块（`sector_phase.favorable`）/ 基本面（优或中）/
     技术（强），基底已钉市场腿 ⇒ 数其余三腿命中数，检验「≥2 腿」vs「<2 腿」——二值。
- **分档在各挖掘窗内独立定**（五分位切点逐窗算，避免跨窗漂移）；特征值缺失的信号不进该特征的统计，缺失率逐窗报告。

### 读数口径（写死）

- **主量**：命中率提升 `lift_big = P(大单 | 高档) / P(大单 | 全体)`；**护栏量** `lift_loss = P(大亏 | 高档) / P(大亏 | 全体)`。
- **必报**：各档大单率 / 大亏率 / 胜率 / 盈亏比 / margin / 平均每笔收益 / 笔数，五分位单调性，逐年 lift_big，`trade_dist` 分布画像。

### 功效（跑数前回填）

- 量级：R44 同信号集 A ≈ 18.9 万 / B ≈ 38.1 万笔；大单率按 R44 分布（≥3×均亏 ≈ 6.9%，≥+20% 约 4~6%）估 5%。
  五分位高档 n ≈ A 3.8 万 / B 7.6 万，大单率差 1pp（lift 1.2）的 z ≈ 1pp / √(0.05×0.95/38,000) ≈ 9（deff=5 时 ≈ 4）——功效充足。
- **跑数前规则（写死）**：任一特征在任一窗的高档 n < 2,000 或缺失率 > 50% ⇒ 该特征该窗记缺，两窗任一缺 ⇒ 该特征 untested。
  预期 `fund_good` / `resonance3` 在挖掘 A 受 PIT 台账起点（2014-04）限制，可能触发——如实判 untested，不放宽。

### 判据（跑数前写死，逐特征）

- **C1 样本**：两窗高档 n ≥ 2,000 且缺失率 ≤ 50%。
- **C2 右尾提升**：两窗 `lift_big` 均 > 1.2。
- **C3 稳健 + 左尾护栏**：①两窗 `lift_big / lift_loss` 均 > 1（右尾提升快于大亏放大）；②五分位特征的档位单调（各档大单率与档序
  Spearman ≥ 0.8，两窗）/ 二值特征逐年 lift_big > 1 的年份 ≥ 2/3（各窗内）。
- **C4 选择效应**：簇级置换零假设 N=200——每臂在各窗内把特征值按簇（`kit.cluster_ids`）整体置换、7 个特征全部重算，取
  `min(两窗 lift_big)` 的 11 特征 max（v0.443 起，修订节在案）；候选特征的 `min(两窗 lift_big)` > `kit.q95` ⇒ confirmed_pass。
- **判定段（第二批）**：candidate 特征冻结分档切点（挖掘段切点）读判定段一次，判定线 `judgment_line`；C1~C3 同样适用。
- **结局**：C1~C4 全过的特征 = candidate ⇒ 入第二批；判定段过线才进入仓位 / 持有研究立项（另一单元），不直接进 live。

### 写死的风险注记

1. **大单率提高可能只是波动率更大**：高波动股大单与大亏都多——C3① 护栏就是为此；仍须报 `vol60` 分档对照（描述性）。
2. **基本面 PIT 起点 2014-04**：挖掘 A 大部分年份无基本面证据 ⇒ `fund_good` / `resonance3` 大概率在 A 窗 untested，结论只能等判定段或
   新窗口；不允许用「只看 B 窗」替代。
3. **技术分 ≥60 与 J<13 深超卖天然互斥**（R28 ④、v0.155：三面共振 B 臂与深水赢家 0.06% vs 3.86%）——`tech_high` 高档样本可能偏小、
   且偏向非深超卖票，读数要连同 `dist_high250` 一起看。
4. **板块腿有前视偏差**：`sector_phase` 依赖板块成分，成分是当前快照（R4 板块腿 A 窗读数异常高的同一来源）⇒ `legs_aligned`
   的板块腿越早越偏；判读时另报「去掉板块腿的两腿计数」对照（描述性）。
5. **幸存者宇宙**（R14）：小盘 / 高回撤档的退市票缺失会抬高大单率读数——小盘档结论降一级证据。
