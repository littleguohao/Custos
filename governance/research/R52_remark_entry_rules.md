## 证据与过程

### 实验单元（写死）

- **信号集**：B1 现行交易集同口径——日 J<13 ∧ 0AMV 做多（`exit_campaign.warm_v0_signals` 的 j_low 信号），collect_all（每个信号日一笔）。
- **窗口**：只读挖掘 A（2000~2016）、挖掘 B（2022~2026-09-04）；`load_window.mining_violation` 校验；段末隔离带 `clip_entries`；
  前向窗（等待 20 根 + 持有）越过段末的信号整笔剔除（两臂同剔，保配对）。判定段 / holdout 不读。
- **出场**：`plan_rules_replay.LIVE_PARAMS`（与 R47 参照格同），成本 25bp；所有臂同一出场。
- **参照臂 B0**：信号日收盘进场。
- **等待臂 W1~W4**：从信号日次根起 20 根内找首个满足条件的 bar（`remark_rules.WAIT_COND` 的 `w_green_shrink` / `w_fractal` /
  `w_zero` / `w_stable`，判定只读 ≤ 当根），在该 bar 收盘进场；20 根内未出现 ⇒ **放弃**（不交易）。
- **过滤臂 F1~F4**：信号日当根满足风险状态（`remark_rules.STATE_CHECK` 的 `s_vol_down` / `s_green_grow` / `s_dead_cross` /
  `s_far_zero`）⇒ 放弃，否则同 B0 当根进场。
- 0 轴远近按 owner 2026-11-13 指正口径：相对 MACD 120 根摆幅 20%（与价格无关）。

### 读数口径（写死）

- 主量：**margin**（胜率 − 盈亏平衡胜率，`criteria_kit._weighted_margin` 同口径），逐窗计；臂 − B0 的 Δmargin 用
  `criteria_kit.margin_delta_bounds`（按信号簇配对 bootstrap，n_boot=400，簇 = `cluster_ids` max_gap=5）。
- 描述：参与率（臂交易数 / B0 交易数）、等待天数分布、放弃样本在 B0 下的收益（放弃是否躲开亏损）、期望、≥+20% 笔数。

### 功效（跑数前回填）

估：挖掘段 B1 信号 A 段约数万、B 段约数万笔（以 R47 参照格交易数为准，跑数前从生产机 / 快照回填实际簇数）。
等待臂参与率由 141 条复盘估（W1 100%、W2 100%、W3 0%~20%、W4 100%，估）——W3 参与率极低时 C1 可能不过 ⇒ untested。

### 判据（跑数前写死；v0.501 质量门口径）

- **C1 样本**：两窗各自，臂的已实现交易所属信号簇数 ≥ 30（`criteria_kit.MIN_CLUSTERS`）；不过 ⇒ untested。
- **C2 方向**：两窗各自 Δmargin 的 95% 下界 > 0。
- **C3 近年稳定**：挖掘 B 的 2022~2025 逐年 Δmargin 用 `criteria_kit.yearly_stability(null=0)`（可判年同向 ≥ 3/4、任何一年 95% 上界 < 0 即不过）；
  不过 ⇒ 结局最高 provisional。
- **C4 选择效应**：随机臂 N=200（过门臂数，重抽上限 10×N），每臂对同一信号集做与该臂**同参与率**的随机放弃，
  等待臂另按该臂实际等待天数分布随机延后进场；池 = 随机臂 Δmargin（两窗合并口径），候选 Δmargin > 多重比较阈值
  `criteria_kit.batch_threshold(pool, m=8)`（8 臂同批）。
- **结局**：`criteria_kit.verdict_four_state`；C1~C4 全过 = candidate ⇒ 入第二批判定段只读一次；判定段过线后才谈 live
  （改 live 进场时点是语义变更，另行拍板）。

### 写死的风险注记（判读时逐条核对）

1. 等待臂的进场价与 B0 不同，止损 / 止盈基准随之移动——Δmargin 同时含「更好的进场价」和「不同的出场路径」，只报合成效应。
2. 141 条复盘是本单元的灵感来源，属于已看过的数据；那 141 个信号若落在挖掘段，本单元读数会部分重合（描述性，不另剔除），
   判读时不得把复盘结论当作独立证据叠加。
3. 等待 20 根是 owner 批语复盘时写死的窗口，本单元不搜索窗口长度（搜索即另立单元）。

### 定稿修订（v0.536，实现时，跑数前；判据实质不放松）

- 每个信号一次性预算延后 0~20 根进场的交易结果（同一出场、同一截断），所有臂与 C4 随机臂只查表——随机臂的延后天数从该臂实际等待天数分布抽，不回退到 0。
- C4 池值 = 两窗合并 Δmargin 点估计（`criteria_kit._weighted_margin` 同口径）；C4_MIN_POOL = 50（池未满 ⇒ provisional）。
