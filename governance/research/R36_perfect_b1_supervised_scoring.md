## 主题

### 方法论纪律（R 系五轮证伪的教训，跑数前写死）

1. **发现/验证分离**：10 个正例点只用于发现（假设生成、特征提案、诊断）；
   验证必须切换到全宇宙双窗交易语义（高分候选的信号层 margin/盈亏比 vs
   基底）；pre2019 untouched 终审段（2010-2016）保持不动；
2. **后视标注声明**：「最后一天=买点」是事后标注（选择偏差）——在单元头部
   明示，任何读数引用时必须连带声明；
3. 每条结论带证据等级；判据跑数前写死；多重比较显式标注（L3− 封顶）。

### 阶段设计（写死）

- **Phase 0 数据审计（✅ 已完成，本页）**：接入 + 审计 + 钉测

- **Phase 2 进化引擎监督模式挖新因子**：适应度 = 正例点分离度（10 点 vs
  当日全宇宙分位提升）× IC 门（evolution 既有 ICStats 门）× 双窗终审；
  候选最终以**全宇宙信号**身份过 strategy_grid 双窗 + 灵敏度 + 随机对照

  + 同一套闸门。Phase 1 显示既有腿无区分力 ⇒ 不开 Phase 3，直接结论

## 附录 · Phase 1 实施方案（生产机命令草案，跑前 owner 复核）

**目标产物**：10 个买点日的「八段技术分 vs 当日全宇宙分位」落点表 +
各腿分值明细。

步骤建议（生产机，逐日 × 10 买点日）：

```bash
# ① 全宇宙当日打分分布：factor_ic_profile 的 scorer 分值序列机制作载
#    （scorer_score_series 逐日分值）取当日全宇宙八段技术分分布；
#    或直接用 1800 链当日候选池的 score_detail 落盘（若有当日快照）。
# ② 逐买点日（10 个），在当日全宇宙分布上定位案例股的分位：
#    percentile = 全宇宙当日技术分 ≤ 案例股技术分 的比例
# ③ 逐腿对照：案例股各腿分值 vs 全宇宙各腿分位（落点归因）
```

备选实现：给 `factor_ic_profile` 加一个 `--marks code:date,...` 打点参数
（在全宇宙分值序列上标注指定 (code,date) 的分位）——一次性把 10 个
(code, buy_date) 点标出来。工具改动是独立提交（不进本页回填口径）。
