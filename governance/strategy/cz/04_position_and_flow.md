## 一、大盘温度计理论

（原 01 文档 §十二）

将市场热度量化为温度（0-100度），通过月线、周线、日线综合判断：

- **高温区（80-90度+）**：头部区域，风险积聚，随时可能大跌。仓位应降至5-6成甚至更低，等待暴跌后的机会
- **低温区（恐慌暴跌后）**：分批进场的良机。如美股跌至20000点时温度降至27.99度，仓位可加至72%-90%
- **中等温度（60-79度）**：正常操作区间，普通投资者30%仓位，高手可50%上限
- **满仓定义**：的"满仓"=80%仓位，剩余20%作为"带刀侍卫"用于应对突发情况或T+0操作

### 仓位与温度对应关系

| 温度 | 仓位建议 |
|------|----------|
| <30度 | 72%-90%（接近满仓） |
| 30-60度 | 50%-72% |
| 60-80度 | 30%-50% |
| 80-90度 | 5-6成 |
| >90度 | 极度危险，大幅减仓 |

> ⚠️ 注意区分：本节的「温度」是 0-100 度的**月/周/日线综合主观打分**；
> [`02_swing_tactics.md`](02_swing_tactics.md) §三的「温度」是**(涨−跌)÷跌**的
> 客观宽度公式。同名不同义，引用时必须说清是哪个。

## 二、滚动复利法

（原 01 文档 §十三）

### 超短线模式

- 持股时间：15分钟到3天
- 每次追求几个点到十几个点利润
- 适合有时间盯盘、执行力强、抗压能力强的人
- 大跌大买，不跌不买，大涨大卖

### 波段模式

- 在一只股票上精准"低买高卖"，赚取数倍利润
- 不长期持股不动，避免坐过山车
- 结合市场大势和个股股性进行滚动操作

### 核心原则

- 永远不满仓，永远保留10%-15%现金
- 对已有利润的品种不追高，等待回调
- 对反弹无力的品种果断卖出，锁定利润
- 买入前就想好能亏多少、极限位置在哪里

### 止盈纪律

- 盈利5-10个点 -> 卖出30%仓位
- 盈利10-15个点 -> 卖出60%仓位
- 盈利40%以上 -> 部分派发，底仓不动，跌回再买（滚动操作）

### T+0操作示例

- 在55%基础仓位中，可拿出15%进行T+0滚动
- 某股10元买入，涨至10.8元（赚8%），卖出50%仓位
- 次日下跌4%时再买回

### 时空价值交易系统

- 时间：调整周期约为13周
- 空间：跌幅达到70%左右
- 板块见底需要板块内至少2-3只龙头股同时见底，板块指数与龙头个股形成"共振"是启动信号

## 三、资金流向 = 主线密码

（原 01 文档 §14.6——**本节有代码消费**：`core/factors/volume_detectors.py`
的 `_vs_confirmed` 按此实现「峰值日后逐日量 ≥ 峰值×55%」的主线确认判定。
改动本节 = 改代码 + 跑测试，见 `../README.md` 写入规范。）

**核心认知**：99%的人看价格，真正的赢家只看资金流向+量能结构。价格是结果，资金才是因。

**量能优先--一切主线的起点**：
- 放量上涨 -> 主力建仓/抢筹
- 放量下跌 -> 主力换手/洗盘
- 无量波动 -> 散户自娱自乐
- 没有量的热点都是假热点，有量的方向才可能成为主线

**量能持续性--主线是否成立的核心标准**：
- 巨量爆发后，未来7-13个交易日量能必须≥峰值55% -> 主线成立（资金锁仓）
- 连续3天量能<55% -> 主力撤退 -> 高概率暴跌/崩盘
- 主线不是看涨多少，而是看资金留不留

**底部巨量--最有价值的进场信号**：
- 长期下跌后突然放出历史级巨量、价格止跌/震荡 -> 主力"建仓完成"标志
- 底部无量=继续跌，底部巨量=可以干

**无量下跌--行情死亡的开始**：
- 连续13个交易日量能持续萎缩 -> 没人接盘、主力放弃、行情进入"死亡区间"
- 后果：横盘阴跌 或 继续破位下杀

**周线级别--决定生死的大周期**：
- 日线看节奏，周线看命运
- 周线放量突破=中期行情启动，周线量能衰竭=主升浪结束
