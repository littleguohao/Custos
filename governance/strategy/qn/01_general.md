源手册「综合」维度 15 个主题的聚合。核心思想：**以 1.3 大系数箱体与自然箱体测高为核心，
MACD 多周期共振定动能，MA25 定多空分界，多重技术互证不矛盾才动手。**

## 一、总纲（骑牛原版）

**买入条件**
- 自然箱体二分之一位放量（异动量）后，MACD 三浪位置买入
- 下跌后缩量阴线/长阴短柱，优先等倍量阳包阴确认
- MACD 零上金叉做平台突破；零下金叉只做震荡反弹低吸
- 起爆线回踩阴线不破，或阳线实体过线一半以上时介入

**卖出/退出**
- 顶背离（价新高、红柱/线未新高）且跌破两点半价格 → 离场
- 到 1.3 箱体上沿或自然箱体上移半格 50% 位，配合 MACD 缩柱或 DMI 见 60 → 卖
- 死亡钩（金叉后回落下跌）→ 及时止损；ABC 的 B 点确认 / C 点死亡钩 → 坚决卖

**风险·陷阱**
- DMI 只有 70~80% 准确率，不能单独作顶底绝对信号
- 缩量阳线 = 买盘不足，追高易套；起爆线/箱体突破需阳线实体过半，假突破无效
- 周线 MACD 绿柱缩短后创新高，警惕顶背离

## 二、MACD 十大技术理论（区间 + 背离 + 金叉层次）

- **金叉层次**：零下金叉做震荡、零上金叉做平台、再次金叉做主升
- **三区间**：红柱穿透白线（DIF）且白线在零轴上方 = 第一区间（可做多）；
  柱离白线 = 第二区间（减仓/收紧止损）；柱离黄线（DEA）= 第三区间（次日开盘卖出）
- **顶背离**：价新高但红柱高度低于前一波 → 次日收盘附近全卖
- 水下（零轴下）任何穿透都只是反弹位，勿当反转；零轴下金叉/红柱不算强势
- 乖离过大 = 失去支撑力量，追高易站岗
- 周期链：15 分钟 MACD 底背离是 60 分钟金叉的前提；5 分钟上水不参与判断
- 周线不死叉 + 月线红柱 = 中期健康，允许持有；回踩零轴附近可低吸

## 三、大小波段与系数（高抛低吸）

- 大波段用 1.3、小波段用 1.26/1.2，混用失真
- 顶价 ÷1.3 反推支撑位：接近 MA25 且 MACD 有金叉迹象 → 列入低吸观察
- 底价 ×1.3 推目标位：接近目标位出现 MACD 死叉或「反切」→ 卖出
- MA25 附近出下影线可轻仓试多，次日不破前低持有、破位出
- **所有买点须系数位、百分比 68% 位、MACD 信号同时间指向同一价格点，否则不操作**
- 反切（反向切回）信号出现果断离场，不抱幻想
- **卖点必须优先于买点**：死叉或反切出现即卖，不等待支撑确认

## 四、MA25 多空分界与二分一位（盘后交易训练）

- 买前必须先站上 MA25，未站上不买；跌破 MA25 或关键画线位卖
- **线上阴线买、线下阳线抛**（线下阳线抛错了也要抛）
- MACD 柱不红不看；红后等小绿 K，小绿后阳包阴 = 买点
- 二分一位（二一鬼门关）是生死关：不过只看；过掉后在 MA25 上等阴线形成伏击圈
- 判断目标位：下行找大阳线位置，上行找大阴线位置，中间找二分之一位
- 月线 MACD 绿柱时，周线红柱下的日线上涨只是反弹，不当反转主升浪
- 小红柱顶背离一旦跌破小红底 → 后面易出大绿，立即止损
- 倍量第三根不买（第三根为弱）；倍量长上影可能临近压力位
- 缩量阳线/横着涨（幅度收敛）= 走弱，跌破放量阳最低价必须卖

## 五、均线体系：收拢发散 + 级别推演

**收拢发散**
- MA5/10/25/144 四线粘合成一股绳后首次向上发散 = 主升浪启动点，买在发散初期
- 前提：MA144 明显走平上翘；MA144 仍下行时，收拢发散多为反弹非反转
- 三线红检查：MA5>MA10>MA25 且开口向上；新手要求日/周/月三周期均红才买
- 已大幅发散（间距过大）的位置不追高；等收拢后第一根放量阳线突破再介入
- 持有期：MA25 未拐头向下且未有效跌破，持股不动

**级别推演（方向→状态→级别→形态，四环缺一不可）**
1. 先看 144 线方向：向上才做多、向下不做、走平观望
2. 等均线粘合后再找 MACD 金叉，两者同现才考虑介入
3. 确认级别：月线向上时，周线或日线金叉才可操作（小级别服从大级别）
4. 粘合区 K 线形态：阳阳阳 / 大小小小星且未破前低 → 试探买入
- 止损：粘合区下沿或最近 K 线低点；均线重新向下发散即离场
- 常见失效：方向未走平/向上时形态再标准也无效；时间不到（未充分收拢）级别小易反复

## 六、每日复盘法

- 顺序：先看指数周线、日线 MACD 位置 → 再定板块 → 再个股
- 强势板块标准：日线 MACD 红柱零轴上方且高于左侧、白线上零轴
- 以缺口为风控位：缺口不破趋势未坏；关键位放量承接可视支撑，缩量观望
- 均线粘合后变盘需放量阳线确认方向；等二次进场信号，首涨不盲目加仓
- 底部均线粘合 + 温和放量 + MACD 红柱走好 = 第一标的
- 复盘量：涨幅 6% 以上约 300 只 + 换手榜前四五百只（通达信 60 键涨幅榜按换手排序，重点 ≥6%）
- 三线红选股：月/周/日 MACD 红柱同步走高；月线大绿后的日线反弹多为诱多，等 3~5 根月 K 金叉

## 七、超短突破法（5/15/60 分钟突破左日最高价）

- 前提：日线一波调整末端；5 或 15 分钟突破左日最高价
- **量能确认**：该周期成交量 ≥ 昨日 60 分钟量（倍量），小于则放弃
- 强形态加成：放量反包阳线（须 5 分钟收回才算）、秃阳线、叉上阴（5/10 日线上方）
- 超短次日开盘/冲高卖；波段持有则卖在 5 日死叉 10 日的波段压力位
- 止损：跌破买入当日最低价或 5/10 日线
- 假阳线风险：低开走高但收盘未过昨收 = 诱多；突破无量不可买

## 八、其他综合主题（简录）

- **弱分形（骑牛登泰山）**：弱分形形成且二分之一位不破才介入/持仓；MACD 开口向上 + 日线收阳 = 短线信号；周线金叉失败清仓
- **时间错配**：先切前复权保证均线/MACD 连续；成交量同步复权；对比指数时复权状态必须一致；百分比坐标系保持空间比例真实
- **中间高（中顶高/中底高）**：价格与量能同时超过左侧标杆点才成立；中顶高在阴线收盘价潜伏（14:50-14:55），中底高在突破最大量 K 收盘价时买；跌破放量阳线最低价 = 安全性失效
- **八字要诀（抓大放小）**：红柱由大变小 = 卖小红；绿柱由大变小 + 回踩不破前低 = 买小绿；死亡陷阱（下跌横盘后破位）勿抄底，快速拉回前低之上才确认买点
- **阴线启动小技巧**：阴线回踩不破二一位/三一位且缩量、阳线反包时买；144 线仍下行时反弹摸到 144 线立即卖；一字板超 4 个不参与
- **斜横线变盘**：波段顶底平行线为空间坐标，底线不破、顶线放量突破；买点须 MACD 红柱 + 阳包阴/黄金坑同现；价格为主量为辅，价格不动不操作
