中长线大资金战法：周线翻倍（180 周线）与日线翻倍（144 线四要素）。
与我们 MA144/240 中长期结构过滤（v0.7）思路同族，但参数（180 周线）不同。

## 一、周线翻倍技术（大悬空 + 脚踩巨量）

**买入条件（四要素）**
1. 周线大悬空：股价长期在 180 周均线下方运行，跌幅超 50% 且时间跨度足够长
2. 180 周线下方出现相对历史巨量的「脚踩巨量」量能柱（洗盘/建仓动作）
3. 放量突破 180 周均线及平台整理区（180 标杆）
4. 突破当日或次日确认站上平台，MACD 出现肉眼可识别标杆（金叉或零轴上走强）

- 选股路径：涨幅榜发现涨停股 → 切周线核对上述条件 → 介入（潜伏翻倍 vs 主动翻倍）

**卖出/退出**
- 自突破点累计涨幅 ≥100% 逐步减仓
- 跌破 180 周线或平台突破位（止损/止盈线）
- 周线放量滞涨、顶背离、MACD 死叉向下 → 离场
- 潜伏介入者：突破后涨幅未达预期且跌破原平台低点 → 退出

**风险·陷阱**
- 大悬空不完整（下跌时间短、跌幅浅）时突破成功率低
- 假突破：无巨量配合或 MACD 标杆未确认
- 大盘系统性下跌/基本面恶化会阻断翻倍逻辑；潜伏期漫长，资金时间成本高

**操作规则**
- 仅操作周线级别，日线指标不作主要决策依据；只用 180 周线判断空间和标杆
- 买点以突破平台 + 180 线为准，不提前潜伏未确认的平台
- 持仓期收盘不破 180 线/突破平台就一直持有至翻倍目标；破位无条件离场不补仓

## 二、日线翻倍技术（144 线上攻四要素）

**买入条件（四要素齐备）**
1. 144 日均线走平并明显上翘
2. 股价冲高回落至 144 日线 ±10% 以内
3. MACD 双线上零轴
4. 过左风四形式之一：涨停板 / 跳空高开 / 倍量 / 线上阴线

- 左风定位：上涨波取最高阴线开盘价，下跌波取最低阴线收盘价

**卖出/退出**
- 有效跌破 144 日均线；MACD 死叉且双线跌破零轴
- 远离 144 线且放量滞涨；趋势走平拐头向下

**风险·陷阱**
- 144 线未上翘/走平不充分时买入易套；过左风可能是假突破，需量价配合
- 「股票平均五年才一波行情」——避免频繁交易；方向判断错误时技术/消息/基本面均失效

**操作规则**
- 先肉眼确认 144 线低位明显上翘，再看股价是否回踩 ±10% 范围
- MACD 双线必须上零轴，否则不构成三浪买点
- 只做 144 线明显上翘且趋势向上的品种，逆势不参与
