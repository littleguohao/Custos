## 本期研究结论一览（2026-07-17 → 2026-08-06）

⚠️ **这一节记录的是「决定不改规则」**。研究链产出的候选绝大多数被证伪，逐条记下来是为了
避免同一个想法被重新提出、重新验证。完整推导见 `00_governance/B1_BACKTEST_FINDINGS.md`。

### 三周里反复出现的同一类错误（值得单列）

1. **拿不可比的量作比较**：跨 `stop_mode` 比 R → 组内跨 `stop_pct` 比 R → 混样本量 →
   比值口径（尾部R占比 >100% 时方向反）。四次都直接改变了结论。
2. **静默降级**：静默 `except` → 名称表残缺仍覆盖缓存 → TDX 连接永不重连（**同一反模式
   在三处、跨两天犯了三次**）→ Windows 内存探测返回 None 无原因。
3. **事后偏差**：幸存者偏差（vipdoc 只含当前挂牌股）、0AMV regime 阈值事后拟合、
   用最新财报回测（已由 PIT 修正）。
